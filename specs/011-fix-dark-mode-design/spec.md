# Feature Specification: ダークモード時の設定画面・管理画面の配色と視認性修正

**Feature Branch**: `012-fix-dark-mode-design`

**Created**: 2026-11-17

**Status**: Draft

**Related Issue**: #22

**Input**: User description: "GitHub Issue #22: ダークモードの時のデザイン「ダークモードのとき設定画面の背景が白いままなので、ヘッダの文字が見づらくなっている。」"

**Provisional Decisions (Posted on Issue #22)**:
- 対象範囲: 設定画面（本体およびデータ移行ダイアログ内の比較領域）に加え、同一原因で視認性低下が発生しているブックマーク一覧画面（管理画面）もあわせて修正する。
- 背景色のトーン: ライトモード時は従来の薄いグレー背景＋白いカード構成を維持し、ダークモード時はカードより一段暗いページ背景色とすることでカードとの階層感を維持する。
- JSON エディタ: 管理画面の JSON 一括編集ダイアログ内のエディタ表示テーマ（ダークテーマ固定）は既存挙動を維持する。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - ダークモード時の設定画面における背景と文字の視認性確保 (Priority: P1)

ダークモード環境（OS またはブラウザのダークテーマ設定）を利用しているユーザーが Nickmark の設定画面を開いた際、ページ全体の背景がダークモードに適した暗い色になり、ページ上部のヘッダタイトルや戻るボタン、および各設定カードが十分なコントラストで明瞭に視認できる。

**Why this priority**: Issue #22 で直接報告されている主訴であり、ダークモードユーザーが設定画面を開いた直後にヘッダ文字が白地に白文字でほぼ読めないという重大な視認性障害を解消するため。

**Independent Test**: ブラウザ／OS をダークモードに切り替えた状態で設定画面を開き、読み込み直後から画面全体（余白含む）が暗い背景色であり、ヘッダ文字「設定 / Preferences」および戻るボタン、各設定カード内のラベル・説明文が明瞭に読めることを単独で検証できる。

**Acceptance Scenarios**:

1. **Given** ブラウザまたは OS の外観設定がダークモードである、**When** ユーザーが設定画面を開く、**Then** 画面全体の背景（コンテンツ外側・余白領域を含む）が暗い背景色で描画され、ヘッダの見出し文字および戻るボタンが背景と十分なコントラストを保って明瞭に表示される。
2. **Given** 設定画面を表示中にダークモードとライトモードを切り替える、**When** システムのカラースキームが変化する、**Then** ページ背景・カード背景・ヘッダ文字色が即座に追従して適切なコントラストに切り替わる。
3. **Given** ページ読み込み直後の描画タイミング、**When** 設定画面が表示される、**Then** 一瞬だけ白い背景がちらつくことなく、最初からダークモードに適した暗い背景色で表示される。

---

### User Story 2 - 設定画面のデータ移行ダイアログにおける視認性確保 (Priority: P2)

ダークモード環境で設定画面の「Google アカウント同期」を切り替え、ローカルデータとクラウドデータの競合確認ダイアログ（データ移行ダイアログ）が表示された際、比較パネルの背景・枠線・強調表示・テキストがダークモードに適した配色となり、日時やアイテム数が明瞭に読み取れる。

**Why this priority**: 設定画面内の比較パネルもライトモード前提の明るい背景色指定になっており、ダークモード時には白い文字が明るいパネル上に描画されて日時・件数の判断ができなくなるため。同期時のデータ選択という重要な操作の誤認を防ぐ必要がある。

**Independent Test**: ダークモード環境でローカル・クラウド双方にデータが存在する状態で同期トグルを操作してデータ移行ダイアログを開き、比較パネルおよび強調された最新データ側の領域のテキスト・枠線・背景が十分なコントラストで読めることを検証できる。

**Acceptance Scenarios**:

1. **Given** ダークモード環境かつローカル・クラウド双方にブックマークデータが存在する状態、**When** ユーザーが Google アカウント同期のトグルを切り替えてデータ移行ダイアログを表示する、**Then** 比較エリア（Local Data / Cloud Data の枠、最新データ側の強調表示、ラベル、日時、件数）が暗い背景基調の配色となり、すべての文字が明瞭に読み取れる。
2. **Given** ライトモード環境でデータ移行ダイアログを表示する、**When** 比較エリアを確認する、**Then** 従来通り明るい背景と強調表示の視認性が維持される。

---

### User Story 3 - ダークモード時のブックマーク一覧画面（管理画面）における視認性確保 (Priority: P2)

ダークモード環境のユーザーがブックマーク一覧画面（管理画面）を開いた際、設定画面と同様にページ全体の背景がダークモードに適した暗い色になり、ページ上部のヘッダタイトルや設定ボタン、各カードおよび一覧テーブルが明瞭に視認できる。

**Why this priority**: 管理画面も設定画面と同一の構造でページ背景色を指定しており、ダークモード時に白背景＋白文字のヘッダとなって視認性が損なわれているため、設定画面と合わせて UI 全体の一貫性を保つ必要がある。

**Independent Test**: ダークモード環境でブックマーク一覧画面を開き、ページ全体の背景・ヘッダ見出し・設定画面遷移ボタン・カード・テーブルのすべてが十分なコントラストで表示されることを検証できる。

**Acceptance Scenarios**:

1. **Given** ブラウザまたは OS の外観設定がダークモードである、**When** ユーザーがブックマーク一覧画面を開く、**Then** ページ全体の背景が暗い色で描画され、ヘッダの見出し文字および設定アイコンボタンが明瞭に視認できる。
2. **Given** ライトモード環境でブックマーク一覧画面および設定画面を開く、**When** 画面全体を確認する、**Then** 従来通りの薄いグレーのページ背景と白いカードのコントラストが維持され、表示崩れや退行が発生しない。

---

### Edge Cases

- ブラウザの外観設定をページ表示中にライト ⇔ ダークへ切り替えた場合でも、ページを再読み込みすることなく背景色と文字色が連動して切り替わること。
- コンテンツ量が少ない状態（カードが縦方向に少ない場合や画面を縦長に表示した場合）でも、ビューポート下部まで背景色が途切れず均一に塗られること。
- ページ読み込み直後（スタイル適用前後の過渡状態）に白い背景が一瞬表示されるフラッシュ現象（FOUC）が発生しないこと。
- ポップアップ画面（コマンドパレット）がダークモードで読み込まれた場合も、読み込み直後から適切な背景色・文字色で描画されること。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 設定画面のページ全体（ビューポート全体およびコンテンツ領域の背景）は、ダークモード時に暗い背景色を使用し、ヘッダの見出し文字・アイコンボタンおよび各カードとの間に十分な視認性とコントラストを確保しなければならない（MUST）。
- **FR-002**: ブックマーク一覧画面（管理画面）のページ全体も同様に、ダークモード時に暗い背景色を使用し、ヘッダの見出し文字・アイコンボタンおよび各カードとの間に十分な視認性とコントラストを確保しなければならない（MUST）。
- **FR-003**: ライトモード時において、設定画面および管理画面のページ背景は従来の薄いグレー基調・カードは白い背景という視覚的階層を維持し、既存のライトモード表示に退行を起こしてはならない（MUST）。
- **FR-004**: ダークモード時において、設定画面および管理画面のページ背景はカード背景より一段暗い色調とし、カードとページ背景の境界を自然に識別できるようにしなければならない（MUST）。
- **FR-005**: 設定画面のデータ移行ダイアログ内にあるローカルデータ／クラウドデータの比較エリアおよび最新データ側の強調表示は、ライトモード・ダークモード双方で文字色と背景・枠線のコントラスト比が十分に保たれる配色にしなければならない（MUST）。
- **FR-006**: OS またはブラウザのカラースキーム設定（ライト／ダーク）が切り替わった場合、設定画面・管理画面の背景色および文字色はリロードなしで即座に追従しなければならない（MUST）。
- **FR-007**: 設定画面・管理画面・ポップアップ画面の初期 HTML 読み込み段階においても、ダークモード環境で白い背景が一瞬表示されないよう初期背景色を適切に設定しなければならない（MUST）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ダークモード環境で設定画面・管理画面を開いた際、ページ背景とヘッダ文字・アイコンのコントラストが明瞭に視認でき、WCAG AA 基準（通常テキスト 4.5:1 以上、大文字見出し 3:1 以上）を満たすコントラスト比が確保される。
- **SC-002**: ダークモード環境で設定画面のデータ移行ダイアログを表示した際、通常側パネルおよび強調表示側パネルのすべてのテキストが判読可能であり、背景と文字が同化する箇所が 0 件である。
- **SC-003**: ライトモード環境での設定画面・管理画面・ポップアップの見た目に意図しない変化がなく、既存の全機能（ブックマーク管理、並び替え、設定保存、同期移行ダイアログ、ポップアップ検索）の動作に退行がない。
- **SC-004**: 拡張機能のビルドがエラーなく完了し、出力パッケージが更新される。

## Assumptions

- 拡張機能のテーマ切り替えは OS / ブラウザのシステム設定（ライト／ダーク）に自動追従する方式を前提とし、拡張機能独自のテーマ手動切り替え設定 UI の新設は本 Issue のスコープ外とする。
- 管理画面の JSON 一括編集エディタのテーマ設定は既存のままとし、本変更では対象外とする。
- ページ内トースト通知および大量タブオープン確認モーダルは既に暗い基調の配色で視認性が確保されているため変更対象外とする。
