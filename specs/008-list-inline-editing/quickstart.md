# Quickstart Validation Guide: 管理画面一覧の列幅固定・URL省略表示およびインライン編集化

**Feature**: `008-list-inline-editing` | **Date**: 2026-11-15 | **Spec**: [spec.md](file:///Users/sawarame_yasushi/dev/Nickmark/specs/008-list-inline-editing/spec.md)

## 前提条件とビルド手順

1. リポジトリルートで本番ビルドを実行し、TypeScript コンパイルおよび Webpack バンドルがエラーなく完了することを確認する。
   ```bash
   npm run build
   ```
2. Chrome で `chrome://extensions/` を開き、開発者モードで `package/` ディレクトリを読み込む（すでに読み込み済みの場合は「更新」ボタンを押す）。
3. 拡張機能の管理画面（`list.html`、ポップアップ内の歯車横一覧アイコンまたは `:ls`）を開く。

---

## 検証シナリオ

### 1. 固定列幅と URL の 1 行「...」省略表示（User Story 1）

1. 短い URL（例: `https://example.com`）、200 文字を超える長い URL、および長い `javascript:...` ブックマークレットを含む複数ページ分（11 件以上）のテストデータを登録する。
2. ページネーション（1 ページ目 ↔ 2 ページ目）やフォルダ絞り込みドロップダウンを切り替える。
   - **期待結果**: ニックネーム、タイトル、URL、ピン留め、操作の各列幅が一切変動しないこと。
3. 長い URL やブックマークレットが表示されている行を確認する。
   - **期待結果**: 1 行のまま末尾が `...` で省略表示され、行の高さが膨張せず、マウスホバーで完全な URL がツールチップ表示されること。

### 2. ポップアップ廃止とインライン編集・キー操作・バリデーション（User Story 2）

1. 一覧の操作列を確認する。
   - **期待結果**: 従来の編集ボタン（鉛筆アイコン）が存在せず、編集ダイアログも開かないこと。
2. 任意の行の「ニックネーム」「タイトル（空欄行を含む）」「URL」をそれぞれクリックする。
   - **期待結果**: クリックしたセルのみがテキストエリアに切り替わり、自動的にフォーカスが当たること。
3. タイトルを書き換えてテキストエリアの外側をクリックする（または別の行のセルをクリックする）。
   - **期待結果**: 更新完了トーストが表示され、通常表示に戻り変更が保存されること（リロードしても保持されていること）。
4. ニックネームを編集して `Enter` キーを押す（日本語 IME で変換中の `Enter` では確定保存されないことも確認する）。
   - **期待結果**: 改行は挿入されず保存確定し、更新完了トーストが表示されること（`Shift+Enter` でも改行せず確定すること）。
5. URL を編集途中で `Escape` キーを押す。
   - **期待結果**: 変更内容が破棄されて元の値に戻り、保存およびトースト通知が実行されないこと。
6. セルをクリックして何も変更せずにフォーカスを外す。
   - **期待結果**: 更新トーストが出ず通常表示に戻ること。
7. ニックネームまたは URL を空（または `/` のみ）にする、あるいは同一ニックネームに既存の別 URL と同じ URL を入力して確定する。
   - **期待結果**: エラートーストが表示され、データは元の有効な値に保たれること。

### 3. 「開く」ボタンと動的 URL（`%s`）デフォルト値編集（User Story 3）

1. 通常 URL 行の操作列にある「新しいタブで開く」ボタン（外部リンクアイコン）をクリックする。
   - **期待結果**: インライン編集にならず、新しいタブで対象ページが開くこと。ブックマークレット行には「開く」ボタンが表示されないこと。
2. `%s` を含む動的 URL（例: `https://www.google.com/search?q=%s`）の URL セルをクリックする。
   - **期待結果**: URL テキストエリアの下に「引数省略時のデフォルト値（任意）」入力欄が表示されること。
3. URL テキストエリアからデフォルト値入力欄へ `Tab` キーやクリックでフォーカスを移動し、デフォルト値を入力して欄外へフォーカスアウトする。
   - **期待結果**: 入力欄間のフォーカス移動では編集が終了せず、編集セルの外へフォーカスが外れたタイミングで URL とデフォルト値がまとめて保存されること。
4. 動的 URL から `%s` を削除して保存する。
   - **期待結果**: デフォルト値入力欄が消え、保存データから不要な `default_value` が除去されること。

### 4. 多言語即時反映（設定連携）

1. 設定画面で表示言語を「English」⇔「日本語」に切り替え、管理画面で新規追加された「新しいタブで開く」ボタンのツールチップ文言やデフォルト値ラベルが切り替わることを確認する。
