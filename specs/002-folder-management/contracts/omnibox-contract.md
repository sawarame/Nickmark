# オムニボックス インターフェース契約 (Omnibox Contract)

**機能ブランチ**: `002-folder-management`  
**日付**: 2026-11-08  
**対象**: Chrome オムニボックス（キーワード `nm`）における入力構文、サジェストフォーマット、実行規則

---

## 1. 入力構文の仕様

### A. ナビゲーションモード（通常モード）

| 入力パターン | 判定 | 最上位（デフォルト候補） | サジェストリスト（2行目以降） |
|---|---|---|---|
| `nm <folder>/`（末尾スラッシュ） | フォルダ一括オープンの意図 | 📁 **`<folder>/` の全ブックマークを一括オープン** (N tabs) | フォルダ直下・配下の個別ブックマーク一覧 |
| `nm <prefix>`（末尾スラッシュなし） | 個別検索またはフォルダ絞り込み | 通常の個別検索最上位（最高スコア） | 一致する個別ブックマーク一覧 ＋ **📁 `<prefix>/` (Nタブを一括で開く)** |

### B. コマンドモード (`:open` / `:o`)

| コマンド構文 | 挙動 |
|---|---|
| `:open <nickname>` | 指定された単一ニックネームの全 URL を開く（既存動作） |
| `:open <folder>/` | 指定されたフォルダ配下の全ニックネームの URL を再帰的一括オープン |
| `:open <folder>` | フォルダ名に完全一致する階層が存在する場合、配下の全 URL を一括オープン |

---

## 2. オムニボックス サジェスト XML フォーマット

### A. フォルダ一括オープン候補の記述形式
```xml
<description>
  📁 <match><folder>/</match> - Open all bookmarks in folder (N tabs)
</description>
```
- `content`: `folder/`（Enter 時に `onInputEntered` に渡される文字列）

### B. 個別ブックマーク候補の記述形式
```xml
<description>
  <match>work/gh</match> - GitHub <dim>(https://github.com)</dim>
</description>
```

---

## 3. 実行時遷移とハンドラ仕様 (`onInputEntered`)

1. **一括オープンの判定**:
   - 入力値が末尾 `/` で終わる、または `:open <folder>` の場合:
     - 該当フォルダに所属する全ニックネームを取得。
     - 重複 URL を除外した対象 URL リストを生成。
     - 対象 URL 数が `maxBatchOpenTabs`（デフォルト 20）以下の場合:
       - バックグラウンドタブで全件オープン。各ブックマークのスコアを更新。
     - 対象 URL 数が `maxBatchOpenTabs` を超える場合:
       - アクティブタブ上に確認プロンプトを注入、または一覧画面（`list.html`）へ遷移して確認を求める。
