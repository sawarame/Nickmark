# Feature Specification: ポップアップのコマンドパレット化とオムニボックス移行案内

**Feature Branch**: `006-popup-command-palette`

**Created**: 2026-11-14

**Status**: Draft

**Input**: User description: "現在ショートカットを入力したら登録のポップアップが表示されますが、現在アドレスバーで入力している機能をこのポップアップに移行したいです。ショートカットもoption+shift+dは押しずらいので、もう少し押しやすいショートカットに変更したいです。ポップアップの登録機能は廃止し、ブックマークはコマンド(:add)で登録するように統一します。アドレスバーのオムニボックス機能は残したままにしますが、移行期間のためで、将来的にはこちらも廃止する予定です。また現行のオムニボックスを使用しようとした時はショートカット版のポップアップを使用するように促す候補を表示するようにしてください。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - ショートカット起動のコマンドパレットによる検索とナビゲーション (Priority: P1)

ユーザーはより押しやすいショートカットキー（Mac は `Cmd+Shift+U`、Windows / Linux は `Ctrl+Shift+U`）またはツールバーアイコンから拡張機能ポップアップを起動し、従来の登録フォームではなくコマンドパレット型の検索入力欄を使って、ニックネーム検索、動的 URL（`%s`）展開、フォルダ一括オープン、およびブックマークレットの実行をポップアップ上から直接行えるようにしたい。

**Why this priority**: これまでアドレスバー（`nm`）で行っていた日常のブックマーク検索・遷移体験をそのまま（さらに見やすく快適に）ポップアップへ移行することが本機能の核となる価値であるため。

**Independent Test**: 新しいショートカットキーまたはアイコンクリックでポップアップを開き、既存のニックネーム・キーワード・フォルダパス・動的 URL・ブックマークレットを入力して実行することで、アドレスバーを使わずに全ナビゲーション機能が完結することを単独で検証できる。

**Acceptance Scenarios**:

1. **Given** ユーザーが任意のタブを開いている状態、**When** ショートカットキー（Mac: `Cmd+Shift+U` / Win・Linux: `Ctrl+Shift+U`）またはツールバーアイコンでポップアップを開く、**Then** 横幅約 600px のコマンドパレット型ポップアップが開き、検索入力欄に自動フォーカスされ、入力が空の状態では候補リストは表示されない。
2. **Given** ポップアップの検索入力欄にフォーカスがある状態、**When** 1文字以上の検索文字列（ニックネーム、キーワード、`ニックネーム 引数` の動的 URL、または `フォルダ名/`）を入力する、**Then** 現行の検索・ソートロジック（マッチ度ティア ＞ ピン留め ＞ 指数減衰スコア ＞ URL 昇順）に従って候補一覧が favicon・種別バッジ（`[JS]`, `[%s]`, フォルダアイコン `📁` 等）・ニックネーム・タイトル・URL とともに表示される。
3. **Given** 通常 URL のブックマーク候補が選択（ハイライト）されている状態、**When** `Enter` キーを押す（または候補をクリックする）、**Then** 現在のタブが対象 URL へ遷移し、ポップアップが閉じる。
4. **Given** 通常 URL のブックマーク候補が選択されている状態、**When** `Cmd+Enter` / `Ctrl+Enter` / `Alt+Enter`（または同修飾キー付きクリック）を行う、**Then** 新しいフォアグラウンドタブ（`Shift` 併用時はバックグラウンドタブ）で URL が開き、ポップアップが閉じる。
5. **Given** フォルダ一括オープン候補（例: `work/`）が選択されている状態、**When** `Enter` を押す、**Then** フォルダ配下の通常 URL がバックグラウンドタブで一斉に開かれる。安全上限件数を超える場合は、他画面へ遷移せずポップアップ内に確認ダイアログ（「すべて開く」「キャンセル」）を表示し、承認時のみタブを開く。
6. **Given** ブックマークレット候補が選択されている状態、**When** `Enter` を押す、**Then** 現在アクティブなタブ上でスクリプトが実行され、成功時はポップアップが閉じる。実行禁止ページや権限未有効等のエラー発生時は管理画面へ遷移せずポップアップ内にエラーメッセージを表示する。

### User Story 2 - `:add` 統一によるブックマーク登録とコマンドのポップアップ完結実行 (Priority: P1)

ユーザーは従来のポップアップ専用登録フォームを使わず、コマンドパレット上で `:add`（`:a`）をはじめとする全コマンド（`:addall`, `:open`, `:rm`, `:ls`, `:prefs`, `:help`）を入力・実行し、結果の通知やエラー・入力不足のフィードバックも別タブへ強制遷移することなくポップアップ内で完結させたい。

**Why this priority**: ポップアップの登録フォームを廃止し登録経路を `:add` コマンドへ一本化するため、コマンド入力・補完・プレビュー・エラー/成功通知がポップアップ内で破綻なく完結することが必須となる。

**Independent Test**: ポップアップ上で `:add`・`:addall`・`:open`・`:rm`・`:ls`・`:prefs`・`:help` をそれぞれ実行し、データの保存・削除・画面遷移が行われること、また特殊ページ（ブラウザ内部ページ等）上でも管理画面へ強制リダイレクトされずポップアップ内で通知が完了することを検証できる。

**Acceptance Scenarios**:

1. **Given** 登録したい Web ページを開いてポップアップを起動した状態、**When** `:add `（または `:a `）と入力する、**Then** 既存ニックネームおよび既存フォルダプレフィックス（`フォルダ名/`）の補完候補と、現在タブ（または第2引数に URL を直接入力した場合はその URL）の登録対象プレビュー（タイトル・URL）が候補領域に表示される。
2. **Given** `:add <ニックネーム> [URL(任意)] [タイトル(任意)]` を入力した状態、**When** `Enter` を押す、**Then** ブックマークが保存（既存同一ニックネーム＋同一 URL でタイトル指定時は更新）され、管理画面へ遷移せずポップアップ内に一時的な完了メッセージが表示された後、短時間で自動的に閉じる（`Esc` で即座に閉じることも可能）。
3. **Given** `:add`（または `:a`）のみを入力しニックネームが未指定の状態、**When** `Enter` を押す、**Then** 管理画面へ遷移せずポップアップを開いたまま維持し、ニックネームの入力を促すメッセージを表示する。
4. **Given** `:rm <複数URLを持つニックネーム>` を入力し特定 URL を選択していない状態、**When** `Enter` を押す、**Then** 誤削除を防いでポップアップを開いたまま維持し、候補一覧から削除対象の URL を選ぶよう案内する。候補から個別 URL を選択して `Enter` を押した場合は、その URL のみが削除されポップアップ内に完了通知が表示される。
5. **Given** `:ls`、`:prefs`、`:help` のいずれかを入力した状態、**When** `Enter` を押す、**Then** それぞれブックマーク一覧画面、設定画面、またはヘルプページが新しいタブで開き、ポップアップが閉じる。
6. **Given** ユーザーがブラウザ内部ページ（`chrome://` 等）を開いた状態でポップアップから登録・削除コマンドを実行した状態、**When** コマンドが成功または失敗する、**Then** 通知表示のために管理画面タブへ勝手に遷移することなく、ポップアップ内のメッセージ表示のみで完結する。

### User Story 3 - キーボードファーストの補完操作とパレット UI の視認性 (Priority: P2)

ユーザーはコマンドパレット内でホームポジションや最小限のキー移動だけで候補の選択とコマンド・パス補完を行いつつ、必要に応じて一覧画面・設定画面へもワンクリックでアクセスしたい。

**Why this priority**: パワーユーザーにとって `Tab` 補完とハイライト移動が分離されている操作感、および日本語 IME 入力時の誤確定防止は日々の操作精度に直結するため。

**Independent Test**: ポップアップ上で矢印キー、`Ctrl+N`/`Ctrl+P`、`Tab`、日本語 IME 確定の `Enter`、`Esc`、および入力欄右端のアイコンボタンを操作し、意図しない補完上書きや誤送信が起きないことを検証できる。

**Acceptance Scenarios**:

1. **Given** 候補が複数表示されている状態、**When** `↓` / `↑` キー（または `Ctrl+N` / `Ctrl+P`）を押す、**Then** 入力欄の検索文字列は書き換わらず維持されたまま、候補リストのハイライトのみが上下に移動する。
2. **Given** 候補（例: `work/` や `:add work/gh`、`:open dev`）がハイライトされている状態、**When** `Tab` キーを押す、**Then** ハイライト中の候補の入力値（コマンドやフォルダパス等）が検索入力欄へ補完され、続けて引数やサブパスを入力できる（右端のアイコンボタンへフォーカスが移動しない）。
3. **Given** 日本語入力（IME）で変換候補を確定しようとしている状態、**When** 変換確定のために `Enter` キーを押す、**Then** コマンドや URL 遷移は誤実行されず、文字確定のみが行われる。
4. **Given** ポップアップが開いている状態、**When** 入力欄右端の一覧アイコンまたは設定アイコンをクリックする、**Then** それぞれブックマーク一覧画面または設定画面が開き、ポップアップが閉じる。
5. **Given** ポップアップが開いている任意の状態、**When** `Esc` キーを押す、**Then** 操作を実行せずにポップアップが即座に閉じる。

---

### User Story 4 - 移行期間中のオムニボックスでのポップアップ利用促進案内 (Priority: P2)

移行期間中、従来の癖でアドレスバーのオムニボックス（キーワード `nm`）を使い始めたユーザーに対して、既存の検索・コマンド機能を維持しつつ、新しいショートカット版ポップアップ（Mac: `Cmd+Shift+U` / Win・Linux: `Ctrl+Shift+U`）への移行を促す案内候補を表示する。

**Why this priority**: オムニボックス機能を将来廃止する前提において、既存ユーザーが違和感なく新しいショートカット操作を認知・学習できるようにするため。

**Independent Test**: アドレスバーで `nm` + スペースを入力した直後、および検索語やコマンドを入力した状態で、ショートカット版ポップアップの利用を促す候補が表示されること、かつ従来の検索・コマンド遷移も引き続き動作することを検証できる。

**Acceptance Scenarios**:

1. **Given** ユーザーがアドレスバーに `nm ` を入力してオムニボックスセッションを開始した状態、**When** 入力がまだ空であるか検索語・コマンドを入力する、**Then** 通常の検索結果・コマンド候補に加えて、新しいショートカットキー（OS に応じた `Cmd+Shift+U` または `Ctrl+Shift+U`）でポップアップランチャーを使うよう促す案内（および将来的なアドレスバー機能廃止予定の旨）がサジェストに表示される。
2. **Given** オムニボックスでキーワード（例: `nm gh`）やコマンド（例: `nm :add dev`）を入力した状態、**When** そのまま最上位の検索結果やコマンドを実行する、**Then** 移行期間中の後方互換性として従来通り対象 URL への遷移やコマンド実行が完了する。
3. **Given** オムニボックスのサジェストに表示された「ポップアップへの移行案内候補」を選択した状態、**When** `Enter` を押す、**Then** 誤った URL 遷移や破壊的変更は行われず、ショートカット利用を案内する通知またはヘルプ案内を表示して安全に完了する。

---

### Edge Cases

- **検索入力が空の状態**: ポップアップを開いた直後、および文字を入力した後にすべて削除して空にした場合は、候補リストを表示せずプレースホルダーのヒントのみを表示する。
- **検索・コマンド一致なし**: 入力に一致するブックマークやコマンドが存在しない場合は「一致する候補がありません」等の案内を表示し、`Enter` を押しても不正な遷移やクローズは行わない。
- **空白のみ・スラッシュのみの入力**: 空白や `/`・`///` のみを入力した場合は全件ヒットを防ぎ、一致なしとして扱う。
- **既存環境でのショートカットキー変更**: 既に拡張機能をインストール済みのユーザー環境では、ブラウザ仕様上既存のショートカット割り当てが自動上書きされない場合があるため、ヘルプ・仕様および拡張機能ショートカット設定画面での案内を考慮する。
- **候補数が表示領域を超える場合**: 候補リストには最大高さを設け、ポップアップ全体の高さ制限内で快適にスクロールでき、キーボード移動（`↑`/`↓`）に連動して選択中アイテムが表示領域内へ自動スクロールする。
- **動的 URL の `default_value` 設定**: ポップアップの登録フォームが廃止され `:add` に統一されるため、動的 URL（`%s`）の引数省略時デフォルト値の個別編集はブックマーク一覧画面（管理画面）で行う前提とする。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは拡張機能アクションのデフォルトショートカットキーを `Alt+Shift+D`（Mac: `Option+Shift+D`）から `Ctrl+Shift+U`（Mac: `Cmd+Shift+U`）へ変更しなければならない。
- **FR-002**: システムはポップアップ画面から従来のブックマーク登録フォームを廃止し、アドレスバーと同等の検索・遷移・コマンド実行機能を提供するコマンドパレット型ランチャーへ置き換えなければならない。
- **FR-003**: ポップアップは横幅約 600px のレイアウトとし、検索入力欄の右端にブックマーク一覧画面および設定画面を開く控えめなアイコンボタン（キーボードの `Tab` 移動対象外）を配置しなければならない。
- **FR-004**: ポップアップは起動時に検索入力欄へ自動フォーカスし、入力が空の間は候補リストを表示せず、検索欄のプレースホルダーに利用可能な入力ヒント（ニックネーム検索および `:add`, `:open`, `:rm` 等のコマンド例）を表示しなければならない。
- **FR-005**: ポップアップは 1 文字以上の入力に応じて、通常検索（ニックネーム一致・動的 URL `%s` 展開・キーワード絞り込み・タイトル/URL 横断検索・`フォルダ名/` 一括オープン）およびコマンドモード（`:` で始まるコマンド）の候補を生成し、現行と同一の優先順位（マッチ度ティア ＞ ピン留め ＞ 指数減衰スコア ＞ URL 昇順）で並べ替えなければならない。
- **FR-006**: ポップアップの候補リストは各候補に対して種別に応じたアイコン（通常 URL の favicon、フォルダの `📁`、ブックマークレットのコードアイコン、コマンドの専用アイコン）、ニックネーム、タイトル、表示用 URL、およびバッジ（ピン留め、`[JS]`、`[%s]` 等）を表示しなければならない。
- **FR-007**: ポップアップは `↑` / `↓`（および `Ctrl+N` / `Ctrl+P`）で検索文字列を変えずに候補のハイライトのみを移動し、`Tab` キーで選択中候補を入力欄へ補完し、`Esc` キーで実行せずポップアップを閉じなければならない。
- **FR-008**: ポップアップは日本語 IME 変換確定中の `Enter` キー入力による誤実行を防止しなければならない。
- **FR-009**: ポップアップは通常 URL 候補の実行において、`Enter`（または通常クリック）で現在アクティブなタブを遷移させ、`Cmd+Enter` / `Ctrl+Enter` / `Alt+Enter`（または対応修飾キー付きクリック）で新しいフォアグラウンドタブを開き、`Shift` キー併用時は新しいバックグラウンドタブを開かなければならない。また遷移・実行時は既存どおり指数減衰スコアを更新しなければならない。
- **FR-010**: ブックマーク登録はコマンド（`:add` / `:a` および `:addall` / `:aa`）に統一し、ポップアップ上での `:add` コマンドの構文は現行仕様（`:add [name] [url(任意)] [title(任意)]`）と同一としなければならない。
- **FR-011**: ポップアップで `:add`（または `:a`）の引数を入力している間、既存ニックネームに加えてフォルダプレフィックス（`フォルダ名/`）の補完候補を提示し、さらに登録対象となるアクティブタブ（または直接指定された URL）のタイトル・URL プレビューを表示しなければならない。
- **FR-012**: ポップアップで `:add`（または `:a`）をニックネーム未指定のまま実行した場合は、管理画面へ遷移せずポップアップを開いたまま維持してニックネーム入力を促す案内を表示しなければならない。
- **FR-013**: ポップアップ上で実行されるコマンドの結果通知（登録完了・更新・重複・削除完了・バリデーションエラー・`:rm` の複数 URL 選択案内・ブックマークレット実行エラー）は、ブラウザ内部ページ（`chrome://` 等）上であっても管理画面へ強制遷移させずポップアップ内で完結して表示し、成功完了メッセージは短時間の表示後にポップアップを自動クローズ（または `Esc` で即時クローズ）しなければならない。
- **FR-014**: ポップアップからフォルダ一括オープンを実行して安全上限件数を超えた場合、システムはアクティブタブへスクリプト注入を行わず、ポップアップ内に確認 UI（「すべて開く」「キャンセル」）を表示してユーザーの承認後に一括オープンを実行しなければならない。
- **FR-015**: 移行期間中、アドレスバーのオムニボックス機能（キーワード `nm`）は従来の検索・遷移・コマンド実行機能を維持したまま存続させなければならない。
- **FR-016**: オムニボックス（`nm`）が起動・入力された際、システムはショートカット版ポップアップ（OS に応じた `Cmd+Shift+U` または `Ctrl+Shift+U`）の使用を促す移行案内候補（将来的なアドレスバー機能廃止の案内を含む）を表示し、その案内候補が実行された場合でも破壊的操作や誤遷移を起こさず安全に案内して終了しなければならない。
- **FR-017**: ポップアップ内のすべてのラベル・プレースホルダー・確認メッセージ・エラー・完了通知およびオムニボックスの移行案内文言は、日本語・英語双方の多言語リソースに対応しなければならない。

### Key Entities *(include if feature involves data)*

- **コマンドパレット候補 (Command Palette Suggestion)**: ポップアップ内に提示される選択可能アイテム。種別（通常ブックマーク、動的 URL、ブックマークレット、フォルダ一括オープン、コマンド実行、登録プレビュー、補完候補）、表示用タイトル・ニックネーム・URL、ファビコン/種別アイコン情報、バッジ、補完テキスト（`Tab` 補完時に検索欄へ反映される文字列）、実行アクションを含む。
- **実行フィードバック状態 (Execution Feedback State)**: ポップアップ内で完結表示される実行結果・確認状態（成功通知、エラー警告、大量タブオープン確認待ちのフォルダ情報と対象 URL 群）を表す状態。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ユーザーは新しいショートカットキー（`Cmd+Shift+U` / `Ctrl+Shift+U`）でポップアップを起動し、ニックネーム入力から目的ページの表示または `:add` による現在ページ登録までを、マウス操作を一切使わず 5 秒以内に完了できる。
- **SC-002**: 従来のアドレスバー（オムニボックス）で提供していた全操作（通常検索、動的 URL 展開、フォルダ一括オープン、ブックマークレット実行、および `:add`, `:addall`, `:open`, `:rm`, `:ls`, `:prefs`, `:help` の全 7 コマンド系統）の 100% が、ポップアップから同等の結果で実行できる。
- **SC-003**: ブラウザ内部ページ（`chrome://` 等）で登録・削除・フォルダ大量オープン確認を実行した場合でも、意図せず管理画面タブへ遷移するケースが 0 件になる。
- **SC-004**: 現行のオムニボックス（`nm`）を利用した全セッションにおいて、ポップアップ（`Cmd+Shift+U` / `Ctrl+Shift+U`）への移行案内候補が確実に表示されつつ、既存の検索・コマンド実行の成功率が 100% 維持される。
- **SC-005**: 日本語および英語の UI 表示切り替え時、ポップアップおよびオムニボックス移行案内のすべての文言が欠落・未翻訳なく即座に反映される。

## Assumptions

- アドレスバーのオムニボックス機能（`nm`）は本仕様に基づく移行期間中は維持し、十分な移行期間を経た将来の別タスクで完全に廃止する。
- 動的 URL（`%s`）の引数省略時デフォルト値（`default_value`）の登録・変更は、コマンド構文を簡潔に保つため引き続きブックマーク一覧画面（管理画面）の編集機能で行う。
- オムニボックス移行案内候補を表示する際、従来の `nm <検索語>` + `Enter` 即時遷移というユーザーの操作リズムを妨げないよう、既存のデフォルト最上位マッチの実行挙動は維持し、候補リスト内の視認しやすい位置（または空入力時のデフォルト案内）に移行促進候補を提示する。
- ポップアップの視覚スタイル・テーマおよび多言語仕組みは、既存拡張機能全体と統一されたトーンおよび言語設定に従う。
