# Quickstart & Validation Guide: ポップアップのコマンドパレット化とオムニボックス移行案内

**Feature**: `006-popup-command-palette`
**Created**: 2026-11-14

このガイドでは、ビルド後の拡張機能を Chrome に読み込み、仕様（[spec.md](file:///Users/sawarame_yasushi/dev/Nickmark/specs/006-popup-command-palette/spec.md)）および契約（[popup-command-palette-contract.md](file:///Users/sawarame_yasushi/dev/Nickmark/specs/006-popup-command-palette/contracts/popup-command-palette-contract.md)）に沿ってエンドツーエンドで検証する手順を定義します。

## 1. ビルドと拡張機能の再読み込み

1. プロジェクトルートでビルドを実行します:
   ```bash
   npm run build
   ```
   - `package/js/background.js`, `package/js/popup.js`, `package/js/list.js`, `package/js/preferences.js` および `package.zip` がエラーなく生成されることを確認します。
2. Chrome で `chrome://extensions/` を開き、`package/` ディレクトリを読み込んだ Nickmark カードの「更新（再読み込み）」をクリックします。
3. 既存インストール環境の場合は `chrome://extensions/shortcuts` を開き、ショートカットが `Cmd+Shift+U`（Win/Linux: `Ctrl+Shift+U`）になっているか確認します（未更新の場合は手動で割り当てて検証します）。

## 2. 検証シナリオ

### シナリオ A: ショートカット起動と初期表示・UI レイアウト (User Story 1, 3)
1. 任意の Web ページ上で `Cmd+Shift+U`（Win/Linux: `Ctrl+Shift+U`）を押します。
2. **期待結果**:
   - 横幅約 600px のコマンドパレット型ポップアップが開き、検索欄に自動フォーカスされる。
   - 入力が空の状態では候補リストが表示されず、プレースホルダーヒントが表示される。
   - 検索欄右端の一覧・設定アイコンボタンへ `Tab` キーでフォーカスが飛ばない。

### シナリオ B: 検索・ナビゲーション・キーボード操作・タブ遷移 (User Story 1, 3)
1. 登録済みのニックネームやキーワードを入力します。
2. **期待結果**:
   - favicon、種別バッジ（`[JS]`, `[%s]`, `📁`）、タイトル、URL が優先順位通りに並ぶ。
   - `↑` / `↓`（および `Ctrl+N` / `Ctrl+P`）で検索欄の文字列を変えずにハイライトが移動する。
   - `Tab` キーで選択候補が入力欄に補完される。
   - 日本語 IME で変換確定 `Enter` を押しても誤実行されない。
   - `Enter` で現在タブに遷移し、`Cmd+Enter` / `Ctrl+Enter` / `Alt+Enter` で新しいフォアグラウンドタブ（`Shift` 併用でバックグラウンドタブ）に開く。

### シナリオ C: `:add` 統一登録とポップアップ完結型フィードバック (User Story 2)
1. 任意の通常ページ、およびブラウザ内部ページ（`chrome://extensions/` 等）でポップアップを開きます。
2. `:add` のみ入力して `Enter` を押します。
   - **期待結果**: 管理画面へ遷移せず、ポップアップ内でニックネーム入力を促すメッセージが表示される。
3. `:add ` と入力し、既存フォルダ（例: `work/`）が補完候補に出ること、および現在タブのタイトル・URL プレビューが表示されることを確認します。
4. `:add test/sample` を入力して `Enter` を押します。
   - **期待結果**: ブラウザ内部ページ上であっても `list.html` に遷移せず、ポップアップ内に完了メッセージが表示された後、自動で閉じる。
5. `:rm` で複数 URL があるニックネームを URL 未指定で `Enter` します。
   - **期待結果**: 管理画面へ遷移せず、ポップアップ内に個別候補の選択案内が表示される。

### シナリオ D: フォルダ大量オープン確認とブックマークレットエラー (User Story 1, 2)
1. 設定画面で一括オープン上限を一時的に低い値（例: `2`）に設定します。
2. ポップアップから 3 件以上含むフォルダ（例: `work/` や `:open work/`）を実行します。
   - **期待結果**: `chrome://` 等の特殊ページ上でもポップアップ内に確認 UI（「すべて開く」「キャンセル」）が表示され、承認時のみ全タブが開く。
3. `chrome://extensions/` 上でブックマークレットを実行します。
   - **期待結果**: 管理画面へ飛ばず、ポップアップ内に禁止ページである旨のエラーが表示される。

### シナリオ E: オムニボックス移行案内と互換性維持 (User Story 4)
1. アドレスバーで `nm` + スペースを入力します。
   - **期待結果**: デフォルト案内にショートカット版ポップアップ（`Cmd+Shift+U` / `Ctrl+Shift+U`）の利用促進メッセージが表示される。
2. `nm gh` 等を入力し、候補一覧の先頭に移行案内候補が表示されること、かつそのまま `Enter` を押すと従来通り目的のブックマークへ遷移できることを確認します。
3. サジェストから移行案内候補を選択して `Enter` を押します。
   - **期待結果**: 誤った URL 遷移や破壊的処理は行われず、安全に終了する（通常ページ上ではショートカット案内トーストを表示）。
