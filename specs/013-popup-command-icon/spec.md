# Feature Specification: コマンド入力モード時のアイコン表示修正

**Feature Branch**: `014-popup-command-icon`

**Created**: 2026-11-17

**Status**: Draft

**Related Issue**: [#26](https://github.com/sawarame/Nickmark/issues/26)

**Input**: User description: "コマンド入力時のアイコン: コロンを入力してコマンド入力モードになった時は、画像のように虫眼鏡アイコンからコマンド入力アイコンに変更する"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - コマンド入力モード切り替え時の検索欄左側アイコン表示 (Priority: P1)

ユーザーは、コマンドパレット型ポップアップの入力欄にコロン（`:`）を入力してコマンド入力モードに入ったとき、入力欄の左端に表示されている虫眼鏡アイコンが、緑色系のターミナルプロンプト（`>_`）を表すコマンド入力アイコンへ確実に切り替わるようにしたい。これにより、現在が通常の検索モードなのかコマンド入力モードなのかを視覚的に即座に判別できるようにしたい。

**Why this priority**: Issue #26 の直接かつ中核の要求であり、アイコンが消えたり虫眼鏡のままになったりするとモード切り替えの視覚的手がかりが失われるため。

**Independent Test**: ポップアップを開いて初期状態の虫眼鏡アイコンを確認し、次に `:` または `:add dev` のようにコロンで始まる文字列を入力して左端アイコンが `>_` 形状のコマンド入力アイコンに変化すること、さらに文字を削除して通常モードに戻すと再び虫眼鏡アイコンに戻ることを単独で確認できる。

**Acceptance Scenarios**:

1. **Given** ユーザーがコマンドパレット型ポップアップを開き、入力欄が空または通常の検索キーワードが入力されている状態、**When** 入力欄の左端アイコンを確認する、**Then** 通常の検索モードを示す虫眼鏡アイコンが表示されている。
2. **Given** ポップアップの入力欄にフォーカスが当たっている状態、**When** ユーザーが先頭に `:` を含むコマンド文字列（例: `:`、`:add dev`、`:open`）を入力する、**Then** 左端のアイコンが即座に虫眼鏡アイコンから `>_` 形状のコマンド入力アイコン（アクセントカラー表示）へ切り替わる。
3. **Given** コマンド入力モードでコマンド入力アイコンが表示されている状態、**When** ユーザーが先頭の `:` を削除して空欄または通常検索語のみにする、**Then** 左端のアイコンが即座に虫眼鏡アイコンへ戻る。

---

### User Story 2 - コマンド候補一覧における一貫したコマンドアイコン表示 (Priority: P2)

ユーザーは、コマンド入力モード中に表示される候補一覧（コマンド補完候補行）においても、各コマンド候補の左側に欠落や空白ではなく同じ `>_` 形状のコマンド入力アイコンが表示され、入力欄と候補一覧で統一感のある視覚表現を得たい。

**Why this priority**: 検索入力欄と同じアイコン表現が候補リスト側のコマンド行にも求められており、片方だけ空白のままだと UI の一貫性と視認性が損なわれるため。

**Independent Test**: ポップアップで `:` や `:a` を入力してコマンド候補リストを表示したとき、各コマンド候補行の左側アイコン領域に空白ではなく `>_` 形状のコマンドアイコンが視認できることで確認できる。

**Acceptance Scenarios**:

1. **Given** ポップアップでコマンド入力モード（例: `:` または `:add`）に入っている状態、**When** コマンド候補やコマンド補完候補が表示される、**Then** 各コマンド候補行の左端アイコン領域に空白ではなく `>_` 形状のコマンド入力アイコンが表示される。

---

### Edge Cases

- **先頭に空白を含むコマンド入力**: `   :add` のように先頭にスペースを含めて `:` を入力した場合でも、システムがコマンド入力モードと判定する状態と一致してコマンド入力アイコンが表示されること。
- **文字列途中のコロン入力**: `https://example.com` や `foo:bar` のように先頭以外に `:` を含む通常検索では、検索モードとして虫眼鏡アイコンを維持すること。
- **IME 入力中・削除時の遷移**: 日本語 IME 等で文字入力や変換・削除を行ってもレイアウトのがたつき（入力欄の横ズレやアイコン幅の変動）が生じないこと。
- **ライトモード／ダークモード双方での視認性**: テーマがライトモード・ダークモードのいずれであっても、コマンド入力アイコンが十分なコントラストで明瞭に視認できること。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、ポップアップの検索入力欄において通常検索モード（入力の先頭（先頭空白を除く）が `:` で始まらない状態）のとき、左端に虫眼鏡アイコンを表示しなければならない。
- **FR-002**: システムは、ポップアップの検索入力欄においてコマンド入力モード（入力の先頭（先頭空白を除く）が `:` で始まる状態）になったとき、左端の虫眼鏡アイコンを `>_` 形状のコマンド入力アイコンに切り替えて表示しなければならない。
- **FR-003**: コマンド入力アイコンは、Issue #26 の提示画像と同様にアクセントカラー（緑系プライマリカラー）で描画され、虫眼鏡アイコンと同じ配置領域・サイズ感でレイアウトを崩さずに表示されなければならない。
- **FR-004**: システムは、コマンド候補およびコマンド補完候補が候補一覧に表示される際も、各候補の左側アイコンとして `>_` 形状のコマンド入力アイコンを欠落なく描画しなければならない。
- **FR-005**: アイコンの切り替えはユーザーの入力および削除に応じて即座に反映され、ライトテーマ・ダークテーマの両環境で正しく視認できなければならない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: `:` 入力直後および削除直後に、遅延なく（100% の再現性で）虫眼鏡アイコンと `>_` コマンド入力アイコンが切り替わる。
- **SC-002**: コマンド入力モード時の検索入力欄左側アイコンおよびコマンド候補一覧アイコンの欠落（空白表示）発生率が 0% になる。
- **SC-003**: 検索入力モードからコマンド入力モードへの切り替え前後で、入力文字の開始位置の横ズレが 0px（または視覚的に違和感のない同一アイコン枠幅）に保たれる。
- **SC-004**: ライトモードおよびダークモードのいずれの表示環境でも、Issue #26 の参考画像と同等の `>_` コマンド入力アイコンが明瞭に視認できる。

## Assumptions

- **対象画面**: Issue #26 の対象は、虫眼鏡アイコンとコマンドモード（`:` 入力）を持つコマンドパレット型ポップアップ画面とする（アドレスバーや一覧画面・設定画面には虫眼鏡→コマンド切替アイコンは存在しない）。
- **コマンドモード判定基準**: 既存のコマンドモード判定（先頭空白を除いた入力文字列が `:` で始まるか）をそのまま踏襲する。
