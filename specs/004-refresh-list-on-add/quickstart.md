# Quickstart & Verification Guide: ブックマーク一覧タブの自動更新

**Feature Branch**: `004-refresh-list-on-add`  
**Date**: 2026-11-09  
**Related Spec**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md)

本ガイドは、通知表示不可ページからのブックマーク追加時に既存の一覧タブが自動更新される動作を検証するための手順書です。

---

## 前提条件とビルド

1. **プロジェクトのビルド**:
   ```bash
   npm run build
   ```
   ビルドがエラーなく完了し、`package/js/background.js` および `package/js/list.js` が生成されていることを確認します。

2. **Chrome 拡張機能の再読み込み**:
   - Chrome で `chrome://extensions/` を開きます。
   - 「デベロッパー モード」が有効になっていることを確認します。
   - Nickmark のカードにある **再読み込み（更新）アイコン** をクリックします。

---

## 検証シナリオ

### シナリオ 1: 既存の一覧タブを開いた状態での特殊ページからの追加（Primary Flow）

1. **一覧タブを準備する**:
   - 新しいタブで Nickmark のブックマーク一覧画面を開きます（オムニボックスで `nm :ls` と入力して Enter、または拡張機能アイコンのポップアップから開く）。
   - 現在登録されているブックマーク一覧が表示されていることを確認します。
2. **特殊ページに移動する**:
   - 新しいタブを開き、スクリプト実行が制限されるページ（例: `chrome://extensions/` や `chrome://settings/`）を開きます。
3. **ブックマークを追加する**:
   - オムニボックス（アドレスバー）に以下を入力して Enter を押します:
     ```text
     nm :add test-site https://example.com/test
     ```
4. **確認項目 (Expected Results)**:
   - [ ] 事前に開いていたブックマーク一覧画面のタブに自動的にフォーカスが切り替わること。
   - [ ] 画面上部に「追加しました」というトースト通知が表示されること。
   - [ ] **画面を手動リロード（F5 や Cmd+R）することなく、追加した `test-site` が一覧テーブル内に即座に表示されていること**。

---

### シナリオ 2: 一覧タブを閉じた状態での特殊ページからの追加

1. **一覧タブをすべて閉じる**:
   - 開いている Nickmark の一覧画面タブをすべて閉じます。
2. **特殊ページからブックマークを追加する**:
   - 特殊ページ（例: `chrome://version/`）上でオムニボックスから以下を入力して Enter を押します:
     ```text
     nm :add fresh-site https://example.com/fresh
     ```
3. **確認項目 (Expected Results)**:
   - [ ] 新規タブとしてブックマーク一覧画面が開くこと。
   - [ ] トースト通知が表示され、追加した `fresh-site` が一覧に表示されていること。

---

### シナリオ 3: 手動でのタブフォーカス復帰時の確認（Secondary Flow）

1. **一覧タブを開いたまま別タブで作業**:
   - 一覧タブを開いたまま、通常の Web サイト（例: `https://example.com`）のタブを開きます。
2. **オムニボックスから追加**:
   - `nm :add normal-site https://example.com/normal` を実行（この場合、ページ内に直接トーストが表示されます）。
3. **手動で一覧タブに切り替え**:
   - 一覧タブをクリックしてフォーカスを戻します。
4. **確認項目 (Expected Results)**:
   - [ ] 一覧タブに戻った際にも、最新の `normal-site` が一覧テーブル内に反映されていること。

---

## トラブルシューティング

- **一覧が更新されない場合**:
  - `list.html` の開発者ツールコンソールを開き、メッセージ受信時にエラーが発生していないか確認してください。
  - `clearBookmarksCache` が正しく呼び出され、Chrome ストレージから最新データが再フェッチされているか確認してください。
