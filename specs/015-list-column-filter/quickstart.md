# Quickstart & Validation Guide: ブックマーク一覧の列別フィルター機能

**Feature**: `015-list-column-filter`  
**Date**: 2026-11-18

## 1. ビルド手順

```bash
npm ci
npm run build
```

- `package/js/list.js` を含むすべてのバンドルと `package.zip` がエラーなく生成されることを確認する。

## 2. 動作確認シナリオ

1. **単一列フィルターの表示と絞り込み**:
   - ブックマーク一覧画面（`list.html`）を開く。
   - 「ニックネーム」「タイトル」「URL」の各列ヘッダー右端にフィルターアイコンボタンが表示されていることを確認する。
   - 「ニックネーム」列のフィルターボタンをクリックすると、ソートが発火せずに列ヘッダー内にテキストエリアが表示され、自動でフォーカスが当たることを確認する。
   - 検索ワードを入力すると、ニックネームにそのワードを含む行のみにリアルタイムで絞り込まれ、フィルターボタンが強調表示されることを確認する。

2. **複数列 AND 絞り込みとクリア操作**:
   - 「URL」列のフィルターボタンもクリックして検索ワードを入力し、「ニックネーム」と「URL」の両方の条件を満たす行のみが表示されることを確認する。
   - テキストエリア右端のクリアボタン（`×`）をクリックすると入力がクリアされ、再度フィルターボタンをクリックするとテキストエリアが閉じることを確認する。
