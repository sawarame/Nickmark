# クイックスタート・実機検証ガイド: ポップアップ検索でのブラウザ履歴表示

**対象機能**: `007-popup-history-search` | **作成日**: 2026-11-14

## 1. ビルドと拡張機能の読み込み

1. プロジェクトルートで本番ビルドを実行し、エラーなく完了することを確認する:
   ```bash
   npm run build
   ```
2. Chrome で `chrome://extensions/` を開き、「デベロッパーモード」を ON にした状態で [package/](file:///Users/sawarame_yasushi/dev/Nickmark/package/) ディレクトリを読み込む（既に読み込み済みの場合は更新ボタンをクリックする）。

---

## 2. 検証シナリオ

### シナリオ 1: 初期状態（権限未付与・OFF）の確認
1. 拡張機能読み込み直後（または `historySearchEnabled` 未設定状態）でポップアップを開く（`Cmd+Shift+U` / `Ctrl+Shift+U` またはアイコンクリック）。
2. ブラウザ履歴には存在するがブックマークには未登録のサイト名を入力する。
3. **期待結果**:
   - インストール・読み込み時に履歴権限の確認ダイアログが出ていないこと。
   - 「一致する候補が見つかりませんでした。」が表示され、履歴セクション・履歴候補は表示されないこと。

### シナリオ 2: 設定画面からのオプトイン許可と拒否ハンドリング
1. 設定画面（`preferences.html`）を開く。
2. 「ブラウザ履歴検索」カードのトグルをクリックして ON にしようとする。
3. Chrome の権限確認ダイアログが表示されたら、まず **「ブロック / 拒否」** を選択する。
   - **期待結果**: トグルが OFF のまま維持され、拒否された旨の Toast メッセージが表示されること。
4. 再度トグルをクリックし、今度は **「許可」** を選択する。
   - **期待結果**: トグルが ON になり、有効化完了の Toast メッセージが表示されること。ページを再読み込みしても ON が維持されること。

### シナリオ 3: ポップアップ検索での履歴表示・重複除外・上限確認
1. ポップアップを開き、ブックマークと閲覧履歴の双方に一致するキーワード（例: `github` や `google`）を入力する。
2. **期待結果**:
   - 上部にブックマーク候補が表示され、その下に「ブラウザ履歴」セクション見出しと履歴候補が表示されること。
   - ブックマーク候補に表示されている URL と同じ URL の履歴が下部セクションに二重表示されていないこと。
   - 履歴候補が最大 10 件までに制限されていること。
3. ブックマークに 0 件・履歴のみに存在するキーワードを入力する。
   - **期待結果**: 一致なしメッセージではなく、履歴セクションと該当履歴候補が表示されること。

### シナリオ 4: キーボード操作・遷移・スコア非更新の確認
1. ブックマーク候補と履歴候補が両方表示された状態で `↓` / `↑`（および `Ctrl+N` / `Ctrl+P`）を押す。
   - **期待結果**: セクション見出しを飛ばしてブックマーク候補と履歴候補の間をスムーズに移動し、リストが自動スクロールすること。
2. 履歴候補をハイライトした状態で `Tab` キーを押す。
   - **期待結果**: 検索入力欄の文字列が書き換わらないこと。
3. 履歴候補をハイライトした状態で `Enter`（または `Cmd/Ctrl+Enter`、`Shift+Enter`）を押す。
   - **期待結果**: それぞれ現在タブ・新規フォアグラウンドタブ・新規バックグラウンドタブで開き、バックグラウンドタブ時のみポップアップが開いたまま維持されること。
4. 管理画面（`list.html`）やストレージ上のブックマークの `score` / `last_used_at` が履歴遷移で変化していないことを確認する。

### シナリオ 5: モード非干渉・連続入力・権限取り消し耐性
1. ポップアップで `:add ` や `:open `、または `work/`（末尾スラッシュ）を入力する。
   - **期待結果**: 履歴セクション・履歴候補が表示されないこと。
2. 検索欄に高速で文字を入力→削除（空にする）を繰り返す。
   - **期待結果**: 入力が空の状態や古い入力文字列の履歴候補が後から遅れて表示されないこと。
3. `chrome://extensions/` の詳細画面等から拡張機能の履歴権限を取り消す（または設定画面でトグルを OFF にする）。
   - **期待結果**: ポップアップ検索でエラーが発生せず、ブックマーク検索のみが正常に動作し、設定画面では OFF として表示されること。
