# Quickstart & 実機検証ガイド: ブックマークのインポート機能

**Feature**: `012-import-bookmarks` | **Date**: 2026-11-17

## 1. ビルド・自動検証手順

```bash
npm run build
```

- `package/js/` および `package.zip` がエラーなく生成されることを確認する。
- Chrome で `chrome://extensions/` を開き、「デベロッパーモード」有効化の上で `package/` ディレクトリを読み込む（既に読み込み済みの場合は更新アイコンをクリックする）。

---

## 2. E2E 検証シナリオ

### シナリオ 1: Nickmark JSON エクスポート & ラウンドトリップ上書き復元（P1）
1. 管理画面（`list.html`）に複数件のブックマーク（通常 URL、動的 URL `%s` + デフォルト値、ブックマークレット、ピン留め設定を含む）が登録された状態で「エクスポート」をクリックし、JSON ファイルを保存する。
2. 画面上で適当な 1 件を削除または変更した後、「インポート」ボタンをクリックして先ほどの JSON ファイルを選択する。
3. 確認ダイアログにファイル名・`Nickmark JSON`・件数が表示されることを確認し、「上書き」を選択して警告メッセージが表示された状態で「インポート実行」をクリックする。
4. **期待結果**: 削除・変更前の状態（ピン留め・スコア・デフォルト値含む）が 100% 復元され、完了トーストが表示される。

### シナリオ 2: Nickmark JSON のマージインポート（P1）
1. 既存ブックマークが登録された状態で、別ニックネームと一部重複 URL（同一ニックネーム＋同一 URL）を含む JSON ファイルを「インポート」から選択する。
2. デフォルトの「マージ」のまま「インポート実行」をクリックする。
3. **期待結果**:
   - 既存ブックマークはすべて保持される。
   - 新規ニックネーム・新規 URL が追加される。
   - 重複したエントリは重複行として増えず、1 件に統合される。

### シナリオ 3: Chrome ブックマーク HTML インポートとベースフォルダ指定（P1）
1. Chrome のブックマークマネージャ（`chrome://bookmarks`）からエクスポートした HTML ファイル（または複数階層 `<H3>`、空白入りタイトル、ブックマークレット、`place:` スキーム等を含むテスト HTML）を用意する。
2. 管理画面の「インポート」からその HTML ファイルを選択する。
3. 確認ダイアログで形式が `Chrome ブックマーク HTML` と判定されること、およびスキップ対象がある場合はスキップ件数が表示されることを確認する。
4. 取り込み先フォルダに `chrome` を入力し、「マージ」で「インポート実行」をクリックする。
5. **期待結果**:
   - `chrome/ブックマーク-バー/...` のようにフォルダ階層を維持したニックネームで登録され、元のタイトルが `title` 列に表示される。
   - フォルダフィルタのドロップダウンにも新しいフォルダが即座に出現し、ポップアップランチャー（`Option+Shift+D` / `Alt+Shift+D`）から生成されたニックネームで即座に検索・遷移できる。

### シナリオ 4: 不正ファイル・同期 100KB 上限・連続再選択・多言語（P2）
1. 構文エラーの JSON、空ファイル、無関係な HTML ファイルを選択してそれぞれエラー通知が表示され、既存データが変化しないことを確認する。
2. Google アカウント同期を有効にした状態で 100KB 超の JSON をインポート実行し、エラー通知が表示されて既存データが保護されることを確認する。
3. ダイアログを「キャンセル」で閉じた直後に、**同じファイル** を再度選択して正常に確認ダイアログが再び開くことを確認する。
4. 設定画面（`preferences.html`）で言語を English に切り替え、管理画面に戻ってインポートボタンおよびダイアログが英語表記になることを確認する。
