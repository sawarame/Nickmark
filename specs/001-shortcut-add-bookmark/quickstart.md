# クイックスタート検証ガイド (Quickstart Validation Guide)

**機能ブランチ**: `001-shortcut-add-bookmark`
**作成日**: 2026-11-08
**ステータス**: 完了 (Completed)

---

## 1. 事前準備 (Prerequisites)

- Node.js (v20 以上推奨)
- Google Chrome (バージョン 135 以上)

```bash
# 依存関係のインストール
npm install

# プロジェクトのビルド
npm run build
```

ビルドが完了すると、`package/js/popup.js` が生成され、`package.zip` が最新化されます。

---

## 2. 拡張機能のロード (Chrome Setup)

1. Chrome を開き、アドレスバーに `chrome://extensions/` を入力して開く。
2. 画面右上の「デベロッパー モード」を有効化する。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本プロジェクトの `package/` フォルダを選択する。
4. 既に読み込み済みの場合は、Nickmark の「更新（リロード）」アイコンをクリックする。
5. （任意）`chrome://extensions/shortcuts` を開き、「Nickmark」に `Option + Shift + D`（Mac）または `Alt + Shift + D`（Win/Linux）が割り当てられていることを確認する。

---

## 3. 実機検証シナリオ (Validation Scenarios)

### シナリオ 1: ショートカットによる基本登録 (P1)
1. 任意のWebサイト（例: `https://github.com`）を開く。
2. キーボードショートカット（Mac: `Option + Shift + D`, Win: `Alt + Shift + D`）を押す。
   - **確認**: ブラウザ右上に登録ダイアログ（ポップアップ）が即座に開く。
   - **確認**: URL欄に `https://github.com`、タイトル欄に対象ページのタイトルが入力されている。
   - **確認**: ニックネーム入力欄に自動でフォーカスが当たっている。
3. ニックネームに `gh` と入力し、`Enter` キーを押す。
   - **確認**: ダイアログが即座に閉じる。
   - **確認**: Web ページ上部に「'gh' として登録しました！」というトースト通知が表示される。
4. Chrome のアドレスバーに `nm gh` と入力して Enter を押す。
   - **確認**: 登録した GitHub ページへ正しく遷移できる。

---

### シナリオ 2: 既存ニックネームの補完と複数URL登録 (P2)
1. 別のWebサイト（例: `https://gist.github.com`）を開く。
2. ショートカットキーを押して登録ダイアログを開く。
3. ニックネーム欄に `g` と入力する。
   - **確認**: 補完候補に `gh` が表示される。
4. `gh` を選択（またはそのまま入力）して `Enter` キーを押す。
   - **確認**: 保存が完了し、ダイアログが閉じてトーストが表示される。
5. アドレスバーで `nm gh` と入力する。
   - **確認**: サジェスト候補に GitHub と Gist の 2 つの URL が表示され、選択起動できる。

---

### シナリオ 3: ツールバーアイコンクリックとヘッダー導線 (P3)
1. ツールバーの Nickmark アイコンをクリックする。
   - **確認**: ショートカットと同様に登録ダイアログが表示される。
2. ダイアログのヘッダーにある「一覧画面を開く」アイコン（リストアイコン）をクリックする。
   - **確認**: 新しいタブでブックマーク一覧管理画面（`list.html`）が開き、ポップアップが閉じる。
3. 一覧画面上に、先ほど登録した `gh` の 2 つのエントリが正しく表示されていることを確認する。

---

### シナリオ 4: 動的URL（%s）とデフォルト値登録 (P4)
1. 登録ダイアログを開く。
2. URL欄を `https://github.com/search?q=%s` に編集する。
   - **確認**: URLに `%s` を含めた瞬間に、「引数省略時のデフォルト値（任意）」入力欄が現れる。
3. ニックネームに `ghs`、デフォルト値に `nickmark` と入力して Enter を押す。
4. アドレスバーで `nm ghs` のみで Enter を押す。
   - **確認**: `https://github.com/search?q=nickmark` へ遷移する。
