# 検証ガイド (Quickstart): ポップアップ初期表示時の Tips 表示

**Feature**: ポップアップ初期表示時の Tips 表示 (`specs/009-popup-tips/spec.md`)
**Date**: 2026-11-17

## 前提条件

- 依存パッケージがインストール済みであること（`npm install`）
- ソースコードのビルドが成功すること
- Google Chrome（バージョン 135 以降）に `package/` ディレクトリが「パッケージ化されていない拡張機能」として読み込まれていること

## 1. ビルド検証

リポジトリルートで以下を実行し、TypeScript コンパイルおよび Webpack バンドル（`package/js/popup.js` 等の再生成）がエラーなく完了することを確認する。

```bash
npm run build
```

## 2. Chrome 実機検証シナリオ

`chrome://extensions/` で Nickmark を再読み込み（リロード）した後、以下のシナリオを順に確認する。

### シナリオ 1: 起動直後の Tips 表示とランダム性・レイアウト確認

1. 任意の Web ページ上でショートカットキー（Mac: `Option+Shift+D` / Windows・Linux: `Alt+Shift+D`）またはツールバーアイコンからポップアップを開く。
2. **期待結果**:
   - 検索入力欄に自動でフォーカスが当たっている。
   - 検索欄の下部の空白スペースに、電球アイコン・`TIP` ラベルとともに Nickmark の操作ヒントが 1 件表示されている。
   - テキストがポップアップ横幅（600px）からはみ出さず、横スクロールが発生していない。
3. ポップアップを `Esc` で閉じて再度開く操作を数回繰り返す。
4. **期待結果**:
   - 毎回同じ固定文言ではなく、複数の異なる Tips からランダムに選ばれて表示される。

### シナリオ 2: Tips クリックによる切り替えとフォーカス維持

1. ポップアップを開いた直後の状態（検索欄が空、Tips 表示中）で、Tips 領域をクリックする。
2. **期待結果**:
   - 直前に表示されていたものとは異なる別の Tip に切り替わる。
   - 連続で複数回クリックしても、直前と同じ Tip が連続して表示されない。
3. Tip をクリックした直後に、検索入力欄をクリックし直さずそのままキーボードで文字（例: `g`）を入力する。
4. **期待結果**:
   - 1 文字目から取りこぼしなく検索入力欄に入力され、フォーカスが検索欄に維持されていることが確認できる。

### シナリオ 3: 検索入力・消去・通知・確認ダイアログとの共存

1. Tips が表示されている状態で 1 文字以上（例: `a` や `:`）を入力する。
2. **期待結果**:
   - Tips 表示が即座に消え、通常の検索候補またはコマンド候補リストのみが表示される。
3. 入力文字をすべて削除する（またはスペースのみを入力する）。
4. **期待結果**:
   - 候補リストが閉じ、空白領域に Tips が再表示される。
5. `:add` コマンドで登録を実行し、ポップアップ内フィードバック通知が表示された状態を確認する。
6. **期待結果**:
   - フィードバック通知表示中は Tips が非表示となり、約 2.5 秒後に通知が自動消去されると Tips が再表示される。
7. フォルダ一括オープン等で大量タブ確認ダイアログを表示する。
8. **期待結果**:
   - 確認ダイアログ表示中は Tips が表示されない。
9. `Tab` キーを押しても Tips 領域へフォーカスが移らないこと、および `Esc` キーで通常通りポップアップが閉じることを確認する。

### シナリオ 4: 多言語対応（日本語／英語）

1. 設定画面（`:prefs`）を開き、使用言語を「English」に切り替えてからポップアップを開く。
2. **期待結果**:
   - 英語の Tip 文言、ラベル、ツールチップが表示され、レイアウト崩れ・横スクロールがない。
3. 同様に「日本語」に戻し、日本語の Tip が即座に表示されることを確認する。
