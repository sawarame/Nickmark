# Nickmark 拡張機能 仕様書

## 1. 基本コンセプト
ニックネーム（別名）を使ってアドレスバーからブックマークへ瞬時にアクセスするための、キーボード操作特化型 Chrome 拡張機能。
マウス移動を最小限にしたいエンジニアやパワーユーザーをターゲットとする。

## 2. 主要機能

### A. ナビゲーションモード（通常時・移行期間中）
> [!NOTE]
> 本機能はコマンドパレット型ポップアップ（`Option+Shift+D` / `Alt+Shift+D`）への移行期間中として後方互換のために維持されており、将来的に廃止予定です。オムニボックス入力時はショートカット版ポップアップの利用を促す移行案内候補が先頭に表示されます（案内候補を選択して Enter を押しても誤遷移は発生せず、安全な案内のみで終了します）。

アドレスバー（オムニボックス）でキーワード `nm` + スペースの後にニックネームや検索キーワードを入力して起動する（すべて大文字・小文字を区別しない）。

- **入力例**: `nm dev` / `nm aws prod` / `nm gh sawarame/Nickmark` / `nm work/` / `nm /work/`
- **挙動**: 
  - **フォルダ一括オープン**: 入力値が `work/` や `/work/` のように末尾スラッシュで終わる場合（先頭スラッシュの有無を問わず自動正規化）、該当フォルダ配下の全ブックマークを一括オープンする候補が最上位（デフォルト候補）に表示され（フォルダ名と同名の単体ブックマークは開く対象外として除外される）、Enterキーを押すことでバックグラウンドタブ群を一斉に開く（安全上限件数を超える場合は確認プロンプトが表示される）。また、末尾スラッシュなしの入力時（例: `work` や `/work`）でも、一致するフォルダが存在する場合はサジェスト候補リスト内に一括オープン候補が提示される。なお、スラッシュのみ（`/` や `///`）の入力時は空文字として扱われ、全件誤ヒットを防止するガードが働く。
  - 1語目でニックネームを検索しつつ、2語目以降が入力された場合は以下のいずれかとして動作する。
    - **動的URL（`%s` を含む通常URL）**: 2語目以降の文字列を引数として `%s` に展開した URL を候補表示・遷移する。URL のパス部分（`?` や `#` より前）にある `%s` は `/` をパス区切りとして保持したままセグメント単位でエンコードし、クエリ・ハッシュ部分（`?` または `#` 以降）にある `%s` は全体を `encodeURIComponent` でエンコードする。引数が省略された場合は、任意設定の `default_value`（デフォルト値）を `%s` に展開した URL へ遷移し、未設定時は URL のオリジン（トップページ）へ遷移する。
    - **通常URL（`%s` を含まないURL）**: 2語目以降のスペース区切りキーワードで、対象ブックマークのタイトル・URL を AND 絞り込みする。
    - **ブックマークレット（`javascript:` で始まるコード）**: ページ遷移や新規タブ作成は行わず、`chrome.userScripts.execute`（`world: "MAIN"`）を使用して現在アクティブなタブ上でスクリプトを実行する。実行前に先頭の `javascript:` を除去し、`%20` などのパーセントエンコードを `decodeURIComponent` で展開する（生の `%` を含むコードも安全にフォールバック処理する）。また、コード破損防止のためブックマークレット内の `%s` は動的URLのプレースホルダーとしては扱わず、2語目以降のキーワード絞り込み対象とする。`chrome://` やウェブストア等のスクリプト実行禁止ページでの呼び出し時、および Chrome の拡張機能詳細設定で「ユーザー スクリプトを許可する」が有効になっていない場合はエラートーストで通知する。
  - **横断検索**: ニックネームに一致しない場合でも、入力された全キーワードがタイトル・URL 全体に含まれるブックマークを候補に表示する。
  - **デフォルト候補**: 検索結果が存在する場合、デフォルト候補（一番上の行）には「Search for: XXX」等の案内と最上位候補が表示される。そのままEnterを押すと、最上位の候補URLが選択され遷移（ブックマークレットの場合は現在タブで実行）する。
  - **候補表示**: 実際のURL候補は2行目以降に表示され、矢印キーやTabキーで選択・補完が可能。候補を選択すると、オムニボックスにはURLではなく選択したニックネーム（動的URLで引数が入力されている場合は `ニックネーム 引数`）が表示される。候補が1つのみになった場合は、デフォルト候補が「Go to XXX: YYY」（ブックマークレットの場合は「Run XXX [JS]: YYY」）という案内に切り替わる。
- **ソート順**: 
  マッチした候補は以下の優先順位でソートされる。
  1. マッチ度ティア（ニックネーム完全一致 ＞ ニックネーム前方一致 ＞ ニックネーム部分一致 ＞ タイトル・URL横断一致）
  2. `is_pinned`（ピン留め優先）
  3. `score`（指数減衰スコア）の降順
  4. `url`（解決後URL）の昇順

### B. コマンドモード（ `:` プレフィックス ）
コマンドパレット（ポップアップ）またはオムニボックス（移行期間中）内でコロン `:` から始まる文字列を入力することで、ブックマーク登録および拡張機能自体の操作を行う。

- **`:add [name] [url(任意)] [title(任意)]` (エイリアス: `:a`)**:
  - 第2引数が `http://`、`https://`、または `javascript:` で始まる場合は指定された URL（`%s` を含む動的URLやブックマークレットも可）を直接登録し、それ以外の場合は現在開いているアクティブなタブの URL を指定したニックネームで登録する（`javascript:` 指定時はコード内の空白を保持するため第2引数以降すべてをコードとして登録する）。
  - タイトルが省略された場合、現在タブ登録時はタブのタイトルが自動的に使用され、URL直接指定時は空文字となる。
  - ニックネーム入力中は既存ニックネーム候補（ポップアップ上では既存フォルダプレフィックス `フォルダ名/` の補完候補および登録対象タブ/URL のプレビューを含む）が表示される（先頭候補は常に入力値そのままを維持するため、新規ニックネーム登録を妨げない）。
  - 同一ニックネームに同一URLが既に登録されている場合、タイトル引数が指定されていればタイトルを上書き更新して通知し、未指定であれば登録済みである旨を通知する。
  - ニックネームが未指定の場合、ポップアップ上では管理画面へ遷移せずニックネーム入力を促す案内を表示する（オムニボックス上では後方互換として管理画面を開き現在のタブ情報をフォームに自動入力する）。
- **`:addall [name]` (エイリアス: `:aa`)**: 現在のウィンドウで開いているすべてのタブ（`chrome://` などを除く）を、指定したニックネームで一括登録する。ニックネーム入力中は既存ニックネーム候補が補完表示される。ニックネームが未指定の場合はエラー通知を表示する。
- **`:ls`**: 拡張機能のブックマーク一覧画面（管理画面）を開く。
- **`:prefs`**: 拡張機能の設定画面を開く。使用言語の切り替えなどが可能。
- **`:help`**: ヘルプ・ドキュメントページを開く。言語設定に応じて適切な URL（日本語版: `https://sawara.me/extensions/nickmark`, 英語版: `https://sawara.me/en/extensions/nickmark`）が別タブで表示される。
- **`:open [name or folder/]` (エイリアス: `:o`)**: 指定したニックネーム、または指定したフォルダ（例: `work/` または `work`）に紐づくすべての通常 URL を、新しいバックグラウンドタブで一斉に開く（ブックマークレットが含まれている場合は別タブ起動をスキップし、登録エントリがブックマークレットのみの場合はスキップされた旨を通知する）。
  - **フォルダ一括オープン**: フォルダ配下の全ブックマーク（`folder/...`）を再帰的に展開し、重複 URL を自動除外して開く。フォルダ名と同名の単体ブックマーク（未分類エントリ）は開く対象外となる。同名の単体ニックネームとフォルダが両方存在する場合、`:open name/`（末尾スラッシュあり）はフォルダ配下を一括オープンし、`:open name`（末尾スラッシュなし）は単体ニックネームを優先して開く。安全上限件数（デフォルト: 20件）を超える場合は確認プロンプトが表示される。
  - **通知**: 成功時は作業の邪魔にならないようトースト通知を表示しない。ニックネームやフォルダが見つからない等のエラー時のみ通知を表示する。
- **`:rm [name] [url(任意)]`**: 指定したニックネームをストレージから削除する。
  - ニックネームに複数のURLが登録されている場合、サジェスト候補に各URLが一覧表示される。候補から特定のURLを選択してEnterを押すことで、そのURLのみを個別に削除できる。
  - 複数のURLが存在する状態でURLを指定せずに実行した場合、誤削除防止のため削除は中断され、候補から選択するよう通知が表示される。
  - ニックネームが未指定、または存在しない場合はエラー通知を表示する。
- **補完・デフォルト候補**: コマンド入力中、一番上の行には「Search commands for: XXX」や「Run command: XXX」といった案内が表示される。コマンドが入力途中の状態でそのままEnterを押した場合、候補リスト内で最も上位にあるコマンドが自動的に補完されて実行される（例: `:a` でEnterを押すと `:add` が実行される）。

### C. 設定と多言語対応
拡張機能全体の表示言語をカスタマイズできる。

- **言語切り替え**: 設定画面（`preferences.html`）から「日本語」または「英語」を選択可能。
- **一括オープンの安全上限設定**: フォルダ一括オープン時に自動で開く最大タブ数（1〜100件、デフォルト: 20件）を設定可能。設定値は `chrome.storage.local` に保存され、上限超過時は誤爆防止の確認プロンプトが表示される。
- **優先順位**: ユーザーが明示的に設定した言語が優先され、未設定の場合はブラウザの標準言語設定（`chrome.i18n.getUILanguage()`）が使用される。
- **反映範囲**: 管理画面、設定画面、およびバックグラウンドから実行されるトースト通知（登録完了メッセージ等）のすべてに即座に反映される。

### D. 通知・フィードバック
ブラウザ標準の通知（Notifications API）の代わりに、独自のトースト通知システムを使用する。

- **通常ページでの表示**: 
  `activeTab` と `scripting` API を使用し、現在開いているページの上部中央に控えめなトースト通知を注入・表示する。
- **特殊ページ（ブラウザ標準ページ）での挙動**:
  `chrome://newtab` などのスクリプト注入が禁止されているページでは、自動的にブックマーク一覧画面（`list.html`）へ遷移し、画面内で通知を表示する。
  既存の一覧画面タブが既に開かれている場合はそのタブをアクティブにして通知を表示し、同時に最新のブックマーク一覧を自動更新して反映する（手動リロード不要）。バックグラウンドタブのスリープ等による通知の取りこぼしを防ぐため一時ストレージ（`pendingToast`）連携を併用し、他タブから一覧画面タブへフォーカスが復帰した際にも通知と最新データが確実に自動同期される。
- **デザイン**: ダークテーマを基調とした、視認性が高くかつ作業を邪魔しないデザインを採用。

### E. データ管理とストレージ
- **ハイブリッドストレージ**: 高速なアクセスが可能な `chrome.storage.local` と、デバイス間同期が可能な `chrome.storage.sync` を切り替えて使用可能。
- **容量**: `unlimitedStorage` 権限により、ローカル保存時は実質無制限のデータ保存に対応。同期時は Google の制限（合計 100KB）に従う。
- **バックアップ**: エンジニア向けの JSON 一括インポート / エクスポート機能を搭載。

### F. Google アカウント同期
Google アカウントに紐づけて、複数の PC 間でブックマークデータを自動同期する機能。

- **同期の切り替え**: 設定画面（`preferences.html`）から「Google アカウント同期」を有効にできる。
- **データのチャンク化**: `chrome.storage.sync` の 1 項目あたり 8KB という制限を回避するため、データを 8000 バイトずつのチャンクに分割して保存し、読み込み時に自動で結合・復元する。
- **データ移行と競合解決**:
  - 同期の ON/OFF 切り替え時に、データの移行先を選択する「データ移行ダイアログ」を表示する。
  - ローカルとクラウドの両方にデータが存在する場合、それぞれの「最終更新日時（ブックマークの作成・使用日時）」と「アイテム数」を比較表示し、ユーザーが優先するデータを選択できる。
  - トグルの操作は物理的にインターセプト（遮断）されており、ダイアログでユーザーが「承認」するまではステートが変更されない。
- **容量制限チェック**: 同期を有効にする前にローカルデータのサイズをチェックし、100KB を超えている場合は有効化を制限してデータの削減を促す。
- **設定の独立性**: 「同期の有効/無効設定」および「言語設定」は常に `chrome.storage.local` に保存され、各デバイスで独立して管理される。

### G. ブックマーク一覧画面（管理画面）
登録したブックマークを視覚的に管理・編集するためのダッシュボード（`list.html`）。

- **視認性の向上**: URL 列の横に、対象サイトの **favicon（アイコン）** を表示（ブックマークレットの場合はコードアイコンを表示）。どのサイトのブックマークかを直感的に判別可能。
- **クイックアクセス**: 表示されている通常 URL はクリック可能な **外部リンク** となっており、クリックすると新しいタブで対象ページを直接開くことができる（ブックマークレットは誤遷移防止のため非リンクテキストとして表示）。また、ブックマークレット利用時に Chrome の「ユーザー スクリプトを許可する」設定が未有効の場合は案内バナーと設定画面へのショートカットを表示する。
- **データ編集**: 各ブックマークのニックネーム、URL、タイトルの編集や、ピン留め（優先表示）の設定、一括削除などの操作が可能。
- **フォルダ管理**: ニックネームに含まれるスラッシュ（`/`）からフォルダ一覧を自動抽出し、上部のフォルダフィルタで対象フォルダ配下のブックマークのみを瞬時に絞り込み表示（フォルダ名と同名の単体ブックマークは「未分類（ルート）」にのみ表示され、フォルダ一覧には混入しない）。先頭スラッシュ（`/work/gh`）や連続スラッシュを含むデータであっても自動的に正規化（`work/gh`）して認識され、空文字フォルダの誤生成を防ぐ。フォルダ単位の一括オープン、フォルダ名の一括リネーム、および配下の全ブックマーク一括削除（確認ダイアログ付き）が可能（いずれの操作でもフォルダと同名の単体ブックマークは対象外として保護される）。

### H. コマンドパレット型ポップアップランチャー（`popup.html`）
従来のポップアップ登録フォームを廃止し、アドレスバーで行っていた検索・ナビゲーション・コマンド実行機能を統合したキーボードファーストのランチャーダイアログ（`popup.html`）。ブックマーク登録は `:add` / `:addall` コマンドへ統一されている。

- **起動方法**:
  - **ショートカットキー**: Mac は `Option + Shift + D`、Windows / Linux は `Alt + Shift + D`（ブラウザ標準設定 `chrome://extensions/shortcuts` で自由に変更可能）。
  - **ツールバーアイコン**: ブラウザツールバーの Nickmark アイコンをクリックした際にも同様に開く。
- **レイアウトと表示**:
  - 横幅約 600px のコマンドパレット UI とし、起動直後は検索入力欄へ自動フォーカスする。入力が空の状態では候補リストを表示せず、検索欄のプレースホルダーに入力ヒントを表示する。
  - 検索入力欄の右端には「一覧画面を開く」「設定画面を開く」の控えめなアイコンボタンを配置する（`tabindex="-1"` によりキーボードの `Tab` 移動対象外）。
  - 1文字以上の入力により、通常検索（ニックネーム一致・`%s` 動的URL展開・キーワード絞り込み・横断検索・`フォルダ名/` 一括オープン）およびコマンドモード（`:add`, `:addall`, `:open`, `:rm`, `:ls`, `:prefs`, `:help`）の候補を、favicon（フォルダは 📁、ブックマークレットはコードアイコン、コマンドはコマンドアイコン）・ニックネーム・タイトル・URL・ピン留め/種別バッジ付きで表示する。
- **キーボード操作とタブ遷移**:
  - `↑` / `↓`（および `Ctrl+N` / `Ctrl+P`）で入力文字列を変えずに候補のハイライトのみを移動し、`Tab` キーで選択中の候補を検索入力欄へ補完する。
  - 日本語 IME 変換確定中の `Enter` 誤爆を防止する。
  - `Enter`（または通常クリック）で現在のタブへ遷移し、`Cmd+Enter` / `Ctrl+Enter` / `Alt+Enter` で新しいフォアグラウンドタブに開く（いずれも開いた後ポップアップを閉じる）。`Shift+Enter`（単独、または `Cmd/Ctrl/Alt` 併用、`Shift+クリック`）でバックグラウンドタブに開き、バックグラウンドタブ起動時およびフォルダ一括オープン（`:open`）時はポップアップを閉じずに検索欄へフォーカスを維持する。`Esc` キーで実行せずポップアップを閉じる。
- **`:add` 補完とポップアップ完結型フィードバック**:
  - `:add` / `:a` 入力中は既存ニックネームとフォルダプレフィックス（`フォルダ名/`）の補完候補、および登録対象（アクティブタブまたは直接指定 URL）のタイトル・URL プレビューを表示する。
  - 実行結果（登録・更新・重複・削除完了・エラー・`:add` 引数なし・`:rm` 複数 URL 選択案内・フォルダ大量オープン確認ダイアログ・ブックマークレット実行エラー）はすべてポップアップ内で完結表示され、`chrome://` 等の特殊ページ上でも `list.html` へ強制遷移しない（登録・削除等の完了メッセージは一定時間後にメッセージのみ自動で消え、ポップアップは開いたまま検索欄へフォーカスを維持する）。

## 3. 指数減衰アルゴリズム
「直近でよく使っているもの」が上位にサジェストされるよう、遷移が行われるたびにスコアを自動調整する。

- スコア更新ロジック: `Score_new = (Score_old * 0.95 ^ elapsedDays) + 1.0`
- `elapsedDays`: 前回使用時から現在までの経過日数（1日 = `1000 * 60 * 60 * 24` ms として計算）
- 新規登録時の初期スコアは `1.0` とする。

## 4. 拡張機能権限 (Manifest V3)
- `omnibox`: アドレスバー操作用
- `storage`: データ保存用
- `unlimitedStorage`: 容量制限解除
- `tabs`: 現在のタブの取得・新規タブでのページ遷移用
- `activeTab`: 操作中のタブに対する一時的なアクセス権限（通知の表示・ブックマークレット実行用）
- `scripting`: ページ内へのトースト表示スクリプト実行用
- `userScripts`: ブックマークレット（任意の JavaScript コード）の実行用（Chrome 135 以降）
- `contextMenus`: 拡張機能アイコンの右クリックメニュー表示用
- `favicon`: ブックマーク一覧でのアイコン表示用
