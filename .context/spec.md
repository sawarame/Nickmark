# Nickmark 拡張機能 仕様書

## 1. 基本コンセプト
ニックネーム（別名）を使ってコマンドパレット型ポップアップからブックマークへ瞬時にアクセスするための、キーボード操作特化型 Chrome 拡張機能。
マウス移動を最小限にしたいエンジニアやパワーユーザーをターゲットとする。

## 2. 主要機能

### A. 検索・ナビゲーションモード
ショートカットキー（`Option+Shift+D` / `Alt+Shift+D`）またはツールバーアイコンからコマンドパレットを開き、ニックネームや検索キーワードを入力して起動する（すべて大文字・小文字を区別しない）。

- **入力例**: `dev` / `aws prod` / `gh sawarame/Nickmark` / `work/` / `/work/`
- **挙動**: 
  - **フォルダ一括オープン**: 入力値が `work/` や `/work/` のように末尾スラッシュで終わる場合（先頭スラッシュの有無を問わず自動正規化）、該当フォルダ配下の全ブックマークを一括オープンする候補が最上位に表示され（フォルダ名と同名の単体ブックマークは開く対象外として除外される）、Enterキーを押すことでバックグラウンドタブ群を一斉に開く（安全上限件数を超える場合は確認ダイアログが表示される）。また、フルパスだけでなく途中の階層フォルダ（例: `github/repo` に対する `repo` や `repo/`）もセグメント境界（`/` 区切り）起点で一致し（末尾 `/` あり時はサフィックス完全一致、末尾 `/` なし時はサフィックス前方一致）、複数候補が一致した場合はフルパスの大文字・小文字を区別しないアルファベット順で候補一覧に提示される。なお、スラッシュのみ（`/` や `///`）の入力時は空文字として扱われ、全件誤ヒットを防止するガードが働く。
  - 1語目でニックネームを検索しつつ、2語目以降が入力された場合は以下のいずれかとして動作する。
    - **動的URL（`%s` を含む通常URL）**: 2語目以降の文字列を引数として `%s` に展開した URL を候補表示・遷移する。URL のパス部分（`?` や `#` より前）にある `%s` は `/` をパス区切りとして保持したままセグメント単位でエンコードし、クエリ・ハッシュ部分（`?` または `#` 以降）にある `%s` は全体を `encodeURIComponent` でエンコードする。引数が省略された場合は、任意設定の `default_value`（デフォルト値）を `%s` に展開した URL へ遷移し、未設定時は URL のオリジン（トップページ）へ遷移する。
    - **通常URL（`%s` を含まないURL）**: 2語目以降のスペース区切りキーワードで、対象ブックマークのタイトル・URL を AND 絞り込みする。
    - **ブックマークレット（`javascript:` で始まるコード）**: ページ遷移や新規タブ作成は行わず、`chrome.userScripts.execute`（`world: "MAIN"`）を使用して現在アクティブなタブ上でスクリプトを実行する。実行前に先頭の `javascript:` を除去し、`%20` などのパーセントエンコードを `decodeURIComponent` で展開する（生の `%` を含むコードも安全にフォールバック処理する）。また、コード破損防止のためブックマークレット内の `%s` は動的URLのプレースホルダーとしては扱わず、2語目以降のキーワード絞り込み対象とする。`chrome://` やウェブストア等のスクリプト実行禁止ページでの呼び出し時、および Chrome の拡張機能詳細設定で「ユーザー スクリプトを許可する」が有効になっていない場合はポップアップ内にエラー通知を表示する。
  - **横断検索**: ニックネームに一致しない場合でも、入力された全キーワードがタイトル・URL 全体に含まれるブックマークを候補に表示する。
  - **候補表示と選択**: 先頭候補が初期選択状態となり、そのまま Enter を押すと選択中（先頭）の候補へ遷移（ブックマークレットの場合は現在タブで実行）する。矢印キー（`↑` / `↓`）や `Ctrl+N` / `Ctrl+P` で候補移動、`Tab` キーで選択中候補のニックネームやフォルダパスを入力欄へ補完できる。
- **ソート順**: 
  マッチした候補は以下の優先順位でソートされる。
  1. マッチ度ティア（ニックネーム完全一致 ＞ ニックネーム前方一致 ＞ ニックネーム部分一致 ＞ タイトル・URL横断一致）
  2. `is_pinned`（ピン留め優先）
  3. `score`（指数減衰スコア）の降順
  4. `url`（解決後URL）の昇順

### B. コマンドモード（ `:` プレフィックス ）
コマンドパレット（ポップアップ）内でコロン `:` から始まる文字列を入力することで、ブックマーク登録および拡張機能自体の操作を行う。

- **`:add [name] [url(任意)] [title(任意)]` (エイリアス: `:a`)**:
  - 第2引数が `http://`、`https://`、または `javascript:` で始まる場合は指定された URL（`%s` を含む動的URLやブックマークレットも可）を直接登録し、それ以外の場合は現在開いているアクティブなタブの URL を指定したニックネームで登録する（`javascript:` 指定時はコード内の空白を保持するため第2引数以降すべてをコードとして登録する）。
  - タイトルが省略された場合、現在タブ登録時はタブのタイトルが自動的に使用され、URL直接指定時は空文字となる。
  - ニックネーム入力中は既存ニックネーム候補（既存フォルダプレフィックス `フォルダ名/` の補完候補および登録対象タブ/URL のプレビューを含む）が表示される（先頭候補は常に入力値そのままを維持するため、新規ニックネーム登録を妨げない）。
  - 同一ニックネームに同一URLが既に登録されている場合、タイトル引数が指定されていればタイトルを上書き更新して通知し、未指定であれば登録済みである旨を通知する。
  - ニックネームが未指定の場合、ニックネーム入力を促す案内を表示する。
- **`:addall [name]` (エイリアス: `:aa`)**: 現在のウィンドウで開いているすべてのタブ（`chrome://` などを除く）を、指定したニックネームで一括登録する。ニックネーム入力中は既存ニックネーム候補が補完表示される。ニックネームが未指定の場合はエラー通知を表示する。
- **`:ls`**: 拡張機能のブックマーク一覧画面（管理画面）を開く。
- **`:prefs`**: 拡張機能の設定画面を開く。使用言語の切り替えなどが可能。
- **`:help`**: ヘルプ・ドキュメントページを開く。言語設定に応じて適切な URL（日本語版: `https://sawara.me/extensions/nickmark`, 英語版: `https://sawara.me/en/extensions/nickmark`）が別タブで表示される。
- **`:rm [name] [url(任意)]`**: 指定したニックネームをストレージから削除する。
  - ニックネームに複数のURLが登録されている場合、候補リストに各URLが一覧表示される。候補から特定のURLを選択してEnterを押すことで、そのURLのみを個別に削除できる。
  - 複数のURLが存在する状態でURLを指定せずに実行した場合、誤削除防止のため削除は中断され、候補から選択するよう通知が表示される。
  - ニックネームが未指定、または存在しない場合はエラー通知を表示する。
- **補完・選択実行**: コマンドが入力途中の状態でそのまま Enter を押した場合、候補リスト内で選択中（または最上位）のコマンドが実行される（例: `:a` で Enter を押すと `:add` の入力案内が表示される）。`Tab` キーで選択中候補の文字列を入力欄へ補完できる。

### C. 設定と多言語対応
拡張機能全体の表示言語をカスタマイズできる。

- **言語切り替え**: 設定画面（`preferences.html`）から「日本語」または「英語」を選択可能。
- **一括オープンの安全上限設定**: フォルダ一括オープン時に自動で開く最大タブ数（1〜100件、デフォルト: 20件）を設定可能。設定値は `chrome.storage.local` に保存され、上限超過時は誤爆防止の確認プロンプトが表示される。
- **デフォルトで別タブで開く設定**: 設定画面（`preferences.html`）の「ブラウザ履歴検索」の上から「デフォルトで別タブで開く」の有効／無効を切り替え可能（デフォルト: 無効）。有効時は、ポップアップ（`popup.html`）からブックマーク候補およびブラウザ履歴候補を修飾キーなしで開く際、新しいフォアグラウンドタブで開く。さらに「デフォルトで別タブで開く」が有効なときに表示されるサブ設定「“新しいタブ”のときはそのタブで開く」（デフォルト: 無効）を有効にすると、現在開いているタブがブラウザの新しいタブページ（`chrome://newtab/` 等）の場合に限り修飾キーなしで開いた際にそのタブで開く（`Cmd/Ctrl/Alt+Enter` および `Shift+Enter` による新規タブ／バックグラウンドタブ操作は設定にかかわらず有効）。Google アカウント同期が ON の場合は `openInNewTab` および `openInCurrentIfNewTab` キーとして同期・データ移行の対象となる。
- **ブラウザ履歴検索設定（オプトイン）**: 設定画面（`preferences.html`）から「ブラウザ履歴検索」の有効／無効を切り替え可能（デフォルト: 無効）。有効化操作時に任意権限（`optional_permissions: ["history"]`）の許可を求め、許可された場合のみ有効化される。設定値はローカルデバイス固有設定として `chrome.storage.local` に保存され、ブラウザ側で権限が取り消された場合も安全に無効状態へフォールバックする。
- **定番プリセット機能**: 設定画面（`preferences.html`）の「定番プリセット」セクションから、よく使われる検索サービス（動的 URL 15件: `g`, `b`, `y`（言語設定に応じて `search.yahoo.co.jp` / `search.yahoo.com` を自動切替）, `nv`, `bd`, `ddg`, `yt`, `gh`, `map`, `tr`, `wiki`（言語設定に応じて `ja.wikipedia.org` / `en.wikipedia.org` を自動切替）, `amz`, `x`, `npm`, `mdn`）および定番ブックマークレット（3件: `mdlink`（Markdown リンクコピー）, `htmllink`（HTML リンクコピー）, `wayback`（Wayback Machine で表示））をチェックボックスで個別に ON / OFF 切り替え可能（初期状態はすべて OFF、「すべて選択」「すべて解除」による一括操作にも対応）。通常のブックマーク JSON（`bookmarks`）には書き込まず、有効化されたプリセット ID 配列（`enabledPresets`）のみを保存することでストレージ容量をほとんど消費しない。Google アカウント同期が ON の場合は `enabledPresets` も同期対象（`chrome.storage.sync`）となり、ポップアップでの通常検索時に固定スコア（`score: 1.0`, `is_pinned: false`）の仮想エントリとして動的に合成される（同一ニックネーム・同一 URL の手動登録ブックマークが存在する場合は重複表示を除外し、スコア `> 1.0` またはピン留めされたユーザー登録ブックマークを常に優先表示する。一覧画面テーブル・JSON エディタ・エクスポート・`:rm` コマンドの対象には含めない）。なお、`mdlink` および `htmllink` をポップアップから実行する際は、ブラウザのフォーカス／User Activation 制約を回避するためポップアップ自身のコンテキスト内でクリップボードへ直接コピーし（`mdlink` は `[タイトル](URL)`（`[`・`]` エスケープ付き）、`htmllink` は Microsoft Teams 等でハイパーリンクとして認識されるよう HTML エスケープ済みの `<a href="URL">タイトル</a>` を `text/html` と `text/plain` の両 MIME タイプで同時格納）、通常ページではページ内完了トーストを表示してポップアップを閉じ、`chrome://` 等の注入不可ページではポップアップ内で完了を通知する。
- **優先順位**: ユーザーが明示的に設定した言語が優先され、未設定の場合はブラウザの標準言語設定（`chrome.i18n.getUILanguage()`）が使用される。
- **反映範囲**: 管理画面、設定画面、およびバックグラウンドから実行されるトースト通知（登録完了メッセージ等）のすべてに即座に反映される。

### D. 通知・フィードバック
ブラウザ標準の通知（Notifications API）の代わりに、独自のトースト通知システムを使用する。

- **通常ページでの表示**: 
  `activeTab` と `scripting` API を使用し、現在開いているページの上部中央に控えめなトースト通知を注入・表示する。
- **特殊ページ（ブラウザ標準ページ）での挙動**:
  `chrome://newtab` などのスクリプト注入が禁止されているページでは、自動的にブックマーク一覧画面（`list.html`）へ遷移し、画面内で通知を表示する。
  既存の一覧画面タブが既に開かれている場合はそのタブをアクティブにして通知を表示し、同時に最新のブックマーク一覧を自動更新して反映する（手動リロード不要）。バックグラウンドタブのスリープ等による通知の取りこぼしを防ぐため一時ストレージ（`pendingToast`）連携を併用し、他タブから一覧画面タブへフォーカスが復帰した際にも通知と最新データが確実に自動同期される。
- **デザイン**: ダークテーマを基調とした、視認性が高くかつ作業を邪魔しないデザインを採用。

### E. データ管理とストレージ
- **ハイブリッドストレージ**: 高速なアクセスが可能な `chrome.storage.local` と、デバイス間同期が可能な `chrome.storage.sync` を切り替えて使用可能。
- **容量**: `unlimitedStorage` 権限により、ローカル保存時は実質無制限のデータ保存に対応。同期時は Google の制限（合計 100KB）に従う。
- **バックアップ**: エンジニア向けの JSON 一括エクスポート機能、および Nickmark JSON / Chrome 標準ブックマーク HTML からのインポート機能を搭載。

### F. Google アカウント同期
Google アカウントに紐づけて、複数の PC 間でブックマークデータを自動同期する機能。

- **同期の切り替え**: 設定画面（`preferences.html`）から「Google アカウント同期」を有効にできる。
- **データのチャンク化と破損保護**: `chrome.storage.sync` の 1 項目あたり 8KB という制限を回避するため、マルチバイト文字（UTF-8）を考慮してデータを 2,000 文字単位（`sync_data_N` キー）のチャンクに分割して保存し、読み込み時に自動で結合・復元する。また、読み込み時のパース失敗（`CORRUPTED_SYNC_DATA`）や保存時の容量超過（`QUOTA_EXCEEDED`）が発生した場合は、既存データを空で上書きせずエラーを送出する。
- **データ移行と競合解決**:
  - 同期の ON/OFF 切り替え時に、データの移行先を選択する「データ移行ダイアログ」を表示する。
  - ローカルとクラウドの両方にデータが存在する場合、それぞれの「最終更新日時（ブックマークの作成・使用日時）」と「アイテム数」を比較表示し、ユーザーが優先するデータを選択できる。
  - トグルの操作は物理的にインターセプト（遮断）されており、ダイアログでユーザーが「承認」するまではステートが変更されない。
- **容量制限チェック**: 同期を有効にする前にローカルデータのサイズをチェックし、100KB を超えている場合は有効化を制限してデータの削減を促す。
- **設定の独立性**: 「同期の有効/無効設定」および「言語設定」は常に `chrome.storage.local` に保存され、各デバイスで独立して管理される。なお、有効化されたプリセット ID リスト（`enabledPresets`）、デフォルトで別タブで開く設定（`openInNewTab`）、および新しいタブ時に現在タブで開く設定（`openInCurrentIfNewTab`）は、同期 ON 時に `chrome.storage.sync` の独立キーとして同期・データ移行される。

### G. ブックマーク一覧画面（管理画面）
登録したブックマークを視覚的に管理・編集するためのダッシュボード（`list.html`）。

- **固定列幅レイアウトと URL 省略表示**: テーブルは `table-layout: fixed` を用いてニックネーム・タイトル・URL・ピン留め・操作の各列幅を固定化し、データ内容やページ切り替えでレイアウトが変動しないよう最適化されている。URL 列（通常 URL・ブックマークレット共通）は 1 行で末尾 `...` 省略表示され、マウスホバー時のツールチップで完全な URL を確認できる。
- **列別フィルター機能**: 「ニックネーム」「タイトル」「URL」の各列ヘッダー右端にフィルターボタンを配置し、クリックすると列ソートを発火させずにその列ヘッダー内に検索ワード入力用のテキストエリア（クリアボタン付き）が表示される。入力したワード（大文字・小文字非区別、スペース区切り複数ワードは AND 部分一致）で対象列をリアルタイムに絞り込み可能であり、複数列のフィルターおよび上部のフォルダ絞り込みとも AND 条件で連動する（絞り込み適用中の列はフィルターボタンが強調表示される）。
- **視認性とセキュリティ案内**: URL 列の左端に対象サイトの **favicon（アイコン）**（ブックマークレットの場合はコードアイコン）を表示し、どのサイトのブックマークかを直感的に判別可能。一覧テーブルからの直接リンク遷移は行わず、URL 文字列のクリックも含めて管理・編集操作に統一している。また、ブックマークレット利用時に Chrome の「ユーザー スクリプトを許可する」設定が未有効の場合は案内バナーと設定画面へのショートカットを表示する。
- **インライン編集とデータ操作**: 編集用モーダルダイアログを廃止し、一覧上のニックネーム・タイトル・URL の各セルをクリックするだけでその場がテキストエリア（PrimeVue `Textarea`）に切り替わり、直感的に編集できる。フォーカスアウトまたは `Enter` キー（IME 変換確定時を除く、`Shift+Enter` 改行なし）でバリデーション後に即時保存され、`Escape` キーで変更を破棄して元に戻せる。なお、ニックネームの登録・インライン編集・フォルダ名変更・インポート先ベースフォルダ入力時には、IME 変換中の候補操作を除きスペース（半角／全角等の空白文字）を入力できないよう抑止・除去される（既にストレージに保存されているスペース入りニックネームはそのまま維持される）。動的 URL（`%s`）の URL セル編集中は、同一セル内に引数省略時のデフォルト値入力欄もあわせて表示され、まとめて編集・保存できる（`%s` 削除時は不要なデフォルト値を自動除去）。その他、ピン留め（優先表示）トグル、個別削除、JSON 一括編集・エクスポートが可能。
- **フォルダ管理**: ニックネームに含まれるスラッシュ（`/`）からフォルダ一覧を自動抽出し、上部のフォルダフィルタで対象フォルダ配下のブックマークのみを瞬時に絞り込み表示（フォルダ名と同名の単体ブックマークは「未分類（ルート）」にのみ表示され、フォルダ一覧には混入しない）。先頭スラッシュ（`/work/gh`）や連続スラッシュを含むデータであっても自動的に正規化（`work/gh`）して認識され、空文字フォルダの誤生成を防ぐ。フォルダ単位の一括オープン、フォルダ名の一括リネーム、および配下の全ブックマーク一括削除（確認ダイアログ付き）が可能（いずれの操作でもフォルダと同名の単体ブックマークは対象外として保護される）。
- **一覧の並び替え**: 既存の固定 5 列レイアウトおよび列ヘッダークリックによるソート（ニックネーム・タイトル・URL）を維持したまま、上部ツールバーに配置した「並び替え」セレクトから「デフォルト順」「最終使用日時（新しい順／古い順）」「スコア（高い順／低い順）」で対象ブックマーク全体（フォルダ絞り込みおよび全ページ対象）を並び替えできる。最終使用日時・スコアでの並び替え時はピン留め状態によるグループ優先を行わず純粋に各項目の数値で比較し（同値時はニックネーム昇順・URL 昇順で安定表示）、選択状態は端末固有設定として `chrome.storage.local` に保存されて次回以降も引き継がれる（列ヘッダーソート実行時は表示矛盾を防ぐためツールバー選択表示をメモリ上のみデフォルトへ切り替える）。
- **JSON / Chrome ブックマーク HTML インポート**: 管理カードヘッダーの「インポート」ボタンから Nickmark エクスポート JSON（`{ "bookmarks": ... }` または辞書直書き JSON）および Chrome 標準のブックマーク HTML（Netscape Bookmark File Format）を読み込みできる。Chrome HTML 読み込み時は `<H3>` フォルダ階層を `/` 区切りに保ちつつ `/` や空白を `-` へサニタイズしたニックネームを自動生成し、`ADD_DATE` や有効スキーム（`http://`, `https://`, `file://`, `javascript:`）を引き継ぐ（ブラウザ内部スキーム等はスキップ）。実行前のプレビュー確認ダイアログではファイル情報・検出形式・対象件数を確認でき、任意の取り込み先ベースフォルダの指定および適用方式（既存データに重複統合する「マージ」／全置換する「上書き」）を選択できる。同期有効時の 100KB 上限超過や不正構造時は既存データを破壊せずエラー通知を表示する。

### H. コマンドパレット型ポップアップランチャー（`popup.html`）
検索・ナビゲーション・コマンド実行機能を集約したキーボードファーストのランチャーダイアログ（`popup.html`）。ブックマーク登録は `:add` / `:addall` コマンドへ統一されている。

- **起動方法**:
  - **ショートカットキー**: Mac は `Option + Shift + D`、Windows / Linux は `Alt + Shift + D`（ブラウザ標準設定 `chrome://extensions/shortcuts` で自由に変更可能）。
  - **ツールバーアイコン**: ブラウザツールバーの Nickmark アイコンをクリックした際にも同様に開く。
- **レイアウトと表示**:
  - 横幅約 600px のコマンドパレット UI とし、起動直後は検索入力欄へ自動フォーカスする。入力が空（または空白のみ）で通知・確認ダイアログが表示されていない空白状態では、検索欄下部の空きスペースに Nickmark の活用ヒント（Tips）を 1 件ランダム表示する（Tip 領域をクリックすると現在と異なる別の Tip に切り替わり、検索欄へのフォーカスは維持される）。設定項目による非表示は設けず、1 文字以上の入力により即座に候補リストへ切り替わる。
  - 検索入力欄の右端には「一覧画面を開く」「設定画面を開く」の控えめなアイコンボタンを配置する（`tabindex="-1"` によりキーボードの `Tab` 移動対象外）。
  - 1文字以上の入力により、通常検索（ニックネーム一致・`%s` 動的URL展開・キーワード絞り込み・横断検索・`フォルダ名/` または途中フォルダ名による一括オープン候補のアルファベット順表示）およびコマンドモード（`:add`, `:addall`, `:rm`, `:ls`, `:prefs`, `:help`）の候補を、favicon（フォルダは 📁、ブックマークレットはコードアイコン、コマンドはコマンドアイコン）・ニックネーム・タイトル・URL・ピン留め/種別バッジ付きで表示する。
  - **ブラウザ履歴検索（オプトイン有効時）**: 設定画面で履歴検索が有効かつアクセス権限が付与されている場合、通常検索時（`:` コマンドおよび末尾 `/` フォルダ指定を除く）にブックマーク候補の下部へ「ブラウザ履歴」セクションとして一致する履歴候補を最大 10 件まで表示する（ブックマーク候補と重複する URL は自動除外）。履歴候補はキーボード移動の対象に含まれ、通常ブックマークと同じ修飾キー遷移ルールで開くことができるが、履歴候補の選択時 `Tab` キーによる入力欄上書きおよび遷移時の学習スコア更新は行わない。
- **キーボード操作とタブ遷移**:
  - `↑` / `↓`（および `Ctrl+N` / `Ctrl+P`）で入力文字列を変えずに候補のハイライトのみを移動し、`Tab` キーで選択中の候補を検索入力欄へ補完する。
  - 日本語 IME 変換確定中の `Enter` 誤爆を防止する。
  - `Enter`（または通常クリック）で現在のタブへ遷移し（設定画面で「デフォルトで別タブで開く」が有効な場合は新しいフォアグラウンドタブに開く。ただし「“新しいタブ”のときはそのタブで開く」も有効で現在のタブが新しいタブページの場合は現在のタブで開く）、`Cmd+Enter` / `Ctrl+Enter` / `Alt+Enter` で設定にかかわらず新しいフォアグラウンドタブに開く（いずれも開いた後ポップアップを閉じる）。`Shift+Enter`（単独、または `Cmd/Ctrl/Alt` 併用、`Shift+クリック`）でバックグラウンドタブに開き、バックグラウンドタブ起動時およびフォルダ一括オープン時はポップアップを閉じずに検索欄へフォーカスを維持する。`Esc` キーで実行せずポップアップを閉じる。
- **`:add` 補完とポップアップ完結型フィードバック**:
  - `:add` / `:a` 入力中は既存ニックネームとフォルダプレフィックス（`フォルダ名/`）の補完候補、および登録対象（アクティブタブまたは直接指定 URL）のタイトル・URL プレビューを表示する。現在開いているタブがすでに保存済みブックマークに登録されている場合は、登録済みニックネームを含めたお知らせバナーをポップアップ内に表示する（既存操作はブロックせず別ニックネームへの追加登録やタイトル更新はそのまま可能）。
  - 実行結果（登録・更新・重複・削除完了・エラー・`:add` 引数なし・`:rm` 複数 URL 選択案内・フォルダ大量オープン確認ダイアログ・ブックマークレット実行エラー）はすべてポップアップ内で完結表示され、`chrome://` 等の特殊ページ上でも `list.html` へ強制遷移しない（登録・削除等の完了メッセージは一定時間後にメッセージのみ自動で消え、ポップアップは開いたまま検索欄へフォーカスを維持する）。

## 3. 指数減衰アルゴリズム
「直近でよく使っているもの」が上位にサジェストされるよう、遷移が行われるたびにスコアを自動調整する。

- スコア更新ロジック: `Score_new = (Score_old * 0.95 ^ elapsedDays) + 1.0`
- `elapsedDays`: 前回使用時から現在までの経過日数（1日 = `1000 * 60 * 60 * 24` ms として計算）
- 新規登録時の初期スコアは `1.0` とする。

## 4. 拡張機能権限 (Manifest V3)
- `storage`: データ保存用
- `unlimitedStorage`: 容量制限解除
- `tabs`: 現在のタブの取得・新規タブでのページ遷移用
- `activeTab`: 操作中のタブに対する一時的なアクセス権限（通知の表示・ブックマークレット実行用）
- `scripting`: ページ内へのトースト表示スクリプト実行用
- `userScripts`: ブックマークレット（任意の JavaScript コード）の実行用（Chrome 135 以降）
- `contextMenus`: 拡張機能アイコンの右クリックメニュー表示用
- `favicon`: ブックマーク一覧でのアイコン表示用
- `optional_permissions`:
  - `history`: ポップアップでのブラウザ履歴検索をユーザーが設定画面から明示的に有効化した際にのみ許可を要求する任意権限
