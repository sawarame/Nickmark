    コマンドパレット (⌥⇧D / Alt+⇧D)

    どこからでも、思考を止めずに呼び出す。

    Option + Shift + D（Windows / Linux は Alt + Shift + D）を押すだけでコマンドパレットが即座に展開。ニックネームの一致度だけでなくタイトルや URL 全体から横断検索し、開きたいタブの挙動まで自在に選べます。
